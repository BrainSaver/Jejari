설정

관리자는 SUPERVISOR — 비워 두면 .env의 처음 관리자 계정을 씁니다. 태그는 영문 소문자·숫자로, 대회마다 새로. 비밀번호는 이 PC의 화면 서버 메모리에만 두고, 대회가 끝나면 지웁니다. 봇은 사람 참가가 시작될 때 같이 출발합니다. 사람 시간에는 제한이 없고, 다 끝나면 [사람 참가 끝내기]를 누릅니다. [대회 시작]을 누르면 화면이 준비까지 합니다: Docker Desktop 켜기 · 봇 브라우저 설치 · 최신 코드 · 켜져 있던 앱 끄기 · 도커 · DB 패치 · Redis 비우기 · 최신 화면으로 앱 켜기.
