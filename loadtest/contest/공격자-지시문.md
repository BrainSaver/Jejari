## 만들 것

폴더 `loadtest/contest/{종류 이름}/` 에 봇과 `README.md` 한 장 (실행 명령과 필요한 것만. **수법 설명은 쓰지 마** — 대회 뒤에 공개)

- 계정 이메일: `lt{TAG}.{종류 이름}.g{묶음}.{번호}@loadtest.example.com` — 한 사람·조직이 쓰는 계정끼리 같은 묶음 번호
- **명의(본인인증 + 가입)는 최대 6개**
- 환경 변수: `BASE_URL`(기본 http://localhost:8080) · `RUN_ID` · `TAG`(영문 소문자·숫자) · `MODE`
  - `MODE=signup`: 명의만 만들기 (이미 있으면 건너뛰기). 가입은 IP당 1시간에 5명의 정도까지라 미리 만들어 둠
  - `MODE=buy`: 만들어 둔 명의로 구매만 · `MODE=all`: 둘 다
- 결제는 가상 카드번호 (12~19자리, **끝자리 1 = 승인**). 실제 개인정보·카드번호 금지
- 서버를 망가뜨리지 않기: 초당 요청 100 이하
- 언어·도구는 자유. Node 내장 fetch, Playwright(설치돼 있으면) 등

## 로컬에서 시험하기

```bash
docker compose up -d                                   # 인프라 (Oracle·Redis·Mongo·Kafka)
set -a && . ./.env && set +a
LC_ALL=C.UTF-8 TZ=Asia/Seoul ./gradlew bootRun         # 앱 → http://localhost:8080
```

- 시험용 운행: 시드의 판매 중 운행 **`RUN_ID=9001`** (서울 3900023 → 부산 3900114)
- 가입이 429(RATE_LIMITED)로 막히면 로컬 제한을 비우고 다시:
  `docker compose exec -T redis redis-cli --scan --pattern 'rate:signup:*' | xargs -r docker compose exec -T redis redis-cli DEL`
- 끝까지(가입 → 구매 → 결제) 한 번 이상 돌려서 좌석을 사는지 확인해 줘
- **평가 스크립트를 돌리거나 위험 점수 관련 테이블·컬렉션을 조회하지 마**
