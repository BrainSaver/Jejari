# 봇 대회 진행 화면 사용법

버튼 하나로 대회를 엽니다. 운행을 만들고, 봇 명의를 만들고, 사람 참가를 받고, 사람과 봇이 같이 예매하고, 평가와 정리까지 화면이 차례로 합니다.
이 문서는 진행 화면의 "사용 방법"에도 그대로 보입니다.

## 1. 처음 한 번만

- **Docker Desktop**을 켜 둡니다. 저장소 루트에 `.env`가 있어야 합니다 (`.env.example` 참고)
- **Node 18 이상**이 필요합니다. Windows는 **Git Bash**에서 실행합니다 (화면이 bash로 스크립트를 부릅니다)
- **Playwright**를 봇 폴더 하나에만 설치하면 모든 봇이 같이 씁니다:

```bash
cd loadtest/contest/botb && npm i playwright && npx playwright install chromium
```

- 모델 비교까지 보려면 **Python 3.9 이상**이 필요합니다 (없으면 그 단계만 건너뜁니다)
- 단체 할당석이 기본으로 켜져 있습니다 (11-27부터). 대회 운행은 열자마자 판매가 열려 보통 할당석이 안 생기지만, 대회끼리 좌석 수를 꼭 같게 하려면 `.env`에 `JEJARI_GROUP_QUOTA_ENABLED=false`를 넣고 앱을 다시 띄웁니다

## 2. 화면 켜기

저장소 루트의 Git Bash에서:

```bash
node loadtest/contest/web/server.js
```

브라우저로 **http://localhost:8098**을 엽니다. 이 PC에서만 열립니다 (관리자 비밀번호를 다루기 때문).
앱이 꺼져 있어도 됩니다. 대회를 시작하면 화면이 Docker와 앱을 켭니다 (처음이면 3~5분).

## 3. 봇 고르기·추가하기

봇 목록은 `loadtest/contest/bot…/` 폴더에서 읽습니다. 체크한 봇만 대회에 나갑니다.

**+ 봇 추가** 버튼으로 새 봇을 넣습니다. 두 가지 방법이 있습니다.

| 방법 | 언제 | 하는 일 |
|---|---|---|
| **파일 올리기** | 카톡 등으로 봇 파일을 받았을 때 | `loadtest/contest/{이름}/`을 만들고 파일과 `bot.json`을 넣음 |
| **폴더 지정** | 봇이 이 PC의 다른 폴더에 있을 때 (파일이 여러 개 등) | 파일은 그대로 두고 그 폴더에서 실행 (등록은 이 PC에만 저장) |

- **이름**은 `bot` + 영문 소문자 (예: `bote`). 봇이 만드는 계정 이메일의 종류 이름과 **같아야** 평가에 잡힙니다
- **블라인드**: 규칙 코드·평가 문서를 보지 않고 만든 봇이면 체크
- **실행 명령**: 그 폴더 안에서 실행할 명령 (예: `node bot.js`). 화면이 `BASE_URL`·`RUN_ID`·`TAG`·`MODE`를 넣어 부릅니다
- 화면에서 추가한 봇은 **빼기**로 지울 수 있습니다 (두 번 눌러야 지워짐). 깃에 있는 봇(botb·botc 등)은 화면에서 지우지 않습니다
- 팀원이 봇을 main에 올렸다면 `git pull` 뒤 새로 고치면 목록에 나타납니다
- 봇마다 **깃 상태**가 보입니다: `깃`(커밋된 그대로) · `깃에 없음` · `깃과 다름`(고친 파일 있음). 다음 대회에서 **같은 봇**을 다시 돌려야 비교가 되므로, 깃에 없는 봇으로 시작하면 한 번 막고 "한 번 더 누르면 시작"을 묻습니다. 어떤 커밋·어떤 상태의 봇으로 돌렸는지는 `summary.json`의 `commit`·`botGit`에 남습니다

## 4. 대회 시작

1. **관리자 ID·비밀번호**: SUPERVISOR 관리자. **비워 두면 `.env`의 처음 관리자 계정**(`JEJARI_ADMIN_BOOTSTRAP_ID`·`_PASSWORD`)을 씁니다. 비밀번호는 화면 서버 메모리에만 있고, 대회가 끝나면 지워집니다
   - **최신 코드 받기·Redis 비우기**는 기본으로 켜져 있습니다. 사람 참가자가 있으면 Redis 비우기를 끄지 마세요 (1차 때 남은 기록으로 사람이 결제에서 막힘)
2. **태그**: 영문 소문자·숫자 7자 이내, **대회마다 새로** (기본값은 오늘 날짜, 예: `c1123`). 같은 태그는 다시 못 씁니다
3. **사람 시간**: 제한이 없습니다. 사람이 다 끝내면 진행자가 **사람 참가 끝내기**를 누릅니다. 봇은 사람 참가가 시작될 때 같이 출발합니다 (늦게 보내려면 "봇 늦게")
4. **대회 시작**을 누릅니다

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 점검 | Node·Docker·bash·봇 패키지. Docker Desktop이 꺼져 있으면 켜고(Windows), 봇 브라우저(Playwright)가 없으면 설치 | 몇 초 (처음 설치면 2~5분) |
| 준비 | ① 최신 코드 받기(main이고 고친 파일이 없을 때) ② 켜져 있던 앱 끄기(IntelliJ·bootRun 포함) ③ 도커 켜기 ④ DB 패치 전부 순서대로(다시 돌려도 안전) ⑤ Redis 비우기 | 몇 초~몇 분 |
| 앱 켜기 | 최신 화면으로 빌드해 켬, 이용자 화면·관리자 로그인 확인 | 3~5분 |
| 지난 기록 정리 | Redis의 IP별 가입·로그인 시도 카운터만 비움 | 몇 초 |
| 대회 운행 만들기 | 이 PC만 가입·로그인 한도 해제(4시간 뒤 저절로 끝남), 행사·운행 만들고 판매 열기 | 몇 초 |
| 봇 명의 만들기 | 봇마다 `MODE=signup` (동시에). 실패한 봇은 빼고 계속 | 1~5분 |
| 사람 흐름 확인 | 가입 → 결제 → 취소를 한 번 해 봄. 막히면 사람을 부르기 전에 멈춤 | 몇 초 |
| 사람·봇 예매 | 진행자가 사람 참가를 끝내고 봇도 다 끝날 때까지 | 사람 따라 |
| 평가 | 규칙 엔진 → 행동 로그 꺼내기 → 모델 비교 | 2~6분 |
| 정리 | 한도 해제 끝내기 — **실패하거나 중지해도 항상**. 화면을 꺼서 못 돌아도 4시간 뒤 저절로 끝남 | 몇 초 |

## 5. 사람 참가자 받기

"사람·봇 예매" 단계가 되면 화면에 **접속 주소·이메일 형식·운행일·남은 시간**이 크게 뜹니다. 이 화면을 보여 주거나 불러 주면 됩니다.

- 같은 와이파이에서 접속합니다. 안 열리면 이 PC 방화벽에서 **Java(8080)** 를 허용합니다
- 이메일 번호는 **한 사람에 하나씩** 나눠 줍니다 (예: 3번 → `lt{태그}.human.g3.3@loadtest.example.com`)
- 자세한 안내문: `loadtest/contest/사람-참가-안내.md`
- 사람이 다 끝냈으면 **사람 참가 끝내기**를 누릅니다 (누르기 전까지 계속 받음)

## 6. 결과

평가가 끝나면 화면 아래에 표가 나오고, 파일로도 남습니다: `loadtest/contest/results/{태그}/`

| 파일 | 내용 |
|---|---|
| `eval.txt` | 규칙 엔진: 봇마다 가져간 좌석, 막힌 층, 사람 오탐 |
| `compare.md` | 모델 비교 표와 판정 |
| `log.txt` | 전체 진행 로그 |
| `summary.json` | 단계별 결과, 운행 번호 |

## 7. 문제가 생기면

| 증상 | 할 일 |
|---|---|
| 점검: `playwright를 찾지 못함` | 1번의 Playwright 설치를 봇 폴더 하나에서 |
| 점검: `docker compose가 없습니다` | Docker Desktop 켜기 |
| 앱: `관리자 로그인 실패` | ID·비밀번호, SUPERVISOR 권한 확인 |
| 앱: `이용자 화면이 없습니다` | 앱을 끄고 화면에 맡기거나 `./gradlew buildFrontend bootRun` |
| 대회 운행: `운행이 만들어지지 않았습니다` | 같은 열차·같은 날 운행이 이미 있음. 하루 지나서 다시, 또는 `DAYS=71 node …`로 화면 다시 켜기 |
| 사람 흐름 확인에서 멈춤 | 멈춘 단계(결제 등)와 오류 코드를 보고 고친 뒤 **새 태그로** 다시. 사람은 아직 부르지 않은 상태입니다 |
| 봇 하나가 명의 만들기 실패 | 그 봇만 빠지고 계속됩니다. 로그의 `봇이름 │` 줄을 보고 만든 사람에게 전달 |
| 중간에 멈추고 싶음 | **중지**를 두 번. 돌던 봇을 멈추고 한도 해제를 끝냅니다 |

- 화면을 끄면(`Ctrl+C`) 화면이 켠 앱도 같이 꺼집니다. 원래 켜 둔 앱은 그대로입니다
- 정리 단계가 실패했다면 직접: `ADMIN_ID=… ADMIN_PW=… loadtest/contest/day.sh restore`
