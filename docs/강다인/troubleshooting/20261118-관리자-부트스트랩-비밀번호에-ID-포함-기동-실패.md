# [auth] 첫 관리자 계정 만들기가 앱 기동을 멈춤 (비밀번호에 ID 포함, ID에 @)

| 항목 | 내용 |
|---|---|
| 작성자 | 강다인 |
| 날짜 | 2026-11-18 |
| 상태 | 해결 (설정 수정, 코드 변경 없음) |
| 관련 커밋·이슈 | 없음 (`.env` 설정) |

## 1. 문제

- 현상: 관리자 화면을 보려고 `.env`에 `JEJARI_ADMIN_BOOTSTRAP_ID`·`_PASSWORD`를 넣었더니 `bootRun`이 계속 failed, 프론트(5173)는 백엔드가 없어 **502**
- 재현 조건 두 가지
  1. `ID=admin`, `PASSWORD=adminadmin123` → 비밀번호에 ID 포함
  2. `ID=admin@admin.invalid` → ID에 `@` (관리자 ID 형식은 영문 소문자·숫자·`.-_` 3~50자)
- 영향: 앱이 아예 뜨지 않음. 화면에는 502만 보여 원인을 알기 어려움

## 2. 원인

- `AdminBootstrap`은 회원과 같은 비밀번호 규칙(`PasswordPolicy`)을 쓰는데, ID 포함 검사를 위해 ID를 `admin@admin.invalid` 같은 이메일 모양으로 바꿔 넘긴다. 그래서 오류 문구가 "이메일 아이디를 넣을 수 없습니다"로 나와 헷갈렸다.
- 두 번째는 그 설명을 보고 ID 자체를 이메일로 바꾼 것. 관리자 ID에는 `@`가 허용되지 않아 `JEJARI_ADMIN_BOOTSTRAP_ID 형식이 틀렸습니다`로 멈췄다.
- 회원 로그인 화면(`/login`, 이메일 칸 `type="email"`)에서 `admin`을 넣으면 브라우저가 "@가 없습니다"를 띄워, 관리자 로그인(`/admin/login`)과 헷갈린 것도 겹쳤다.

```
IllegalStateException: JEJARI_ADMIN_BOOTSTRAP_PASSWORD가 비밀번호 규칙에 맞지 않습니다: 비밀번호에 이메일 아이디를 넣을 수 없습니다.
IllegalStateException: JEJARI_ADMIN_BOOTSTRAP_ID 형식이 틀렸습니다 (영문 소문자·숫자·.-_ 3~50자)
```

## 3. 해결

| 선택지 | 장점 | 단점 | 채택 |
|---|---|---|---|
| **설정을 규칙에 맞게** (`ID=admin`, ID가 안 들어간 10자 이상 비밀번호) | 바로 해결 | — | ✓ |
| 부트스트랩 오류 문구를 "관리자 ID를 넣을 수 없습니다"로 | 덜 헷갈림 | 회원 규칙 코드 수정 필요 | 후보 (팀 논의) |

- 확인: `POST /api/v1/admin/auth/login` → 200, 로그에 `첫 관리자 계정을 만들었습니다 (admin_id=1, SUPERVISOR)`

## 4. 수치

해당 없음 (설정 문제)

## 5. 정리

- 면접용 한 줄 요약: "부트스트랩이 fail-closed라 잘못된 관리자 설정이면 앱이 뜨지 않았고, 오류 문구가 회원 규칙을 빌려 써서 원인 파악이 늦었다."
- 다음에 비슷한 상황이면: 502가 보이면 프론트가 아니라 **백엔드 로그 마지막 오류 줄**부터 본다. 관리자 로그인은 `/admin/login`, 회원 로그인은 `/login`.
