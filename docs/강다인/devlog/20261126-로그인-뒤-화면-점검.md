### 1. 로그인 뒤 화면 둘러보기

- 공용 서버에 다인 계정으로 직접 로그인한 Chrome에서 내 정보·예매 내역·취소표·알림·단체 예매·검색 → 줄 서기 → 좌석 선택까지 (좌석 잡기·결제는 공용 서버에 기록이 남아 멈춤)
- 폭: PC + 폰(360·390px). 앱 서버가 iframe을 막아(`X-Frame-Options: DENY`) 폰 폭은 페이지의 모바일 CSS(`width <= 959px` 등)를 강제로 켜고 본문 폭을 줄여 흉내 → 겹침·가로 넘침 자동 검사
- 결과: 내 정보·예매 내역·취소표·알림·단체 5개 화면은 PC·폰 모두 겹침 0, 가로 넘침 0

| 문제 | 원인 | 보완 |
