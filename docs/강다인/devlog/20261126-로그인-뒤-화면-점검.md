## 한 일

### 1. 로그인 뒤 화면 둘러보기

- 공용 서버에 다인 계정으로 직접 로그인한 Chrome에서 내 정보·예매 내역·취소표·알림·단체 예매·검색 → 줄 서기 → 좌석 선택 → 좌석 잡기 → 결제 화면 (다인 확인 뒤 좌석 1개를 잡고 결제는 누르지 않고 [잡은 좌석 취소]로 바로 풀었음. 예매 내역에 '취소' 1건 남음)
- 폭: PC + 폰(360·390px). 앱 서버가 iframe을 막아(`X-Frame-Options: DENY`) 폰 폭은 페이지의 모바일 CSS(`width <= 959px` 등)를 강제로 켜고 본문 폭을 줄여 흉내 → 겹침·가로 넘침 자동 검사
- 결과: 내 정보·예매 내역·취소표·알림·단체·좌석·결제 7개 화면은 PC·폰 모두 겹침 0, 가로 넘침 0 (아래 문제는 눈으로 찾은 것)

| 문제 | 원인 | 보완 |
|---|---|---|
| 지난 열차(11/19) 표가 계속 "확정" + 누를 수 없는 [취소] + "지금은 취소할 수 없어요" | 서버는 출발 뒤라 취소 불가(`CANCEL_NOT_ALLOWED`)라고 주는데 화면이 사유를 안 씀 | 도착 시각이 지난 확정 표는 "이용 완료"(회색), 취소 불가면 버튼을 숨기고 "출발한 열차라 취소할 수 없어요" |
| 검색 결과를 내려 본 채 [예매하기] → 좌석 화면이 404px 내려간 채 열려 안내·남은 시간이 안 보임 | SPA라 화면을 옮겨도 스크롤 위치가 그대로 | 경로가 바뀌면 맨 위로 (`ScrollToTop`). 뒤로 가기·`#주소`는 건드리지 않음 |

| 줄 서기: "이미 다른 열차 줄에 서 있어요" 빨간 안내 안의 [열차 다시 찾기]가 거의 안 보임 | 줄 화면(남색 바탕)용 흰 글자 버튼 스타일이 밝은 안내 칸 안에도 적용 | 안내 칸 안에서는 일반 버튼 색 |
