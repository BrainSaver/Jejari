## 한 일

### 1. HEADLESS_HOLD 테스트 기대값을 v34 기준으로

- `RiskScoreBatchInfraTest.화면_녹화_없이_선점한_세션은_HEADLESS_HOLD_조회_없이_진입은_NO_SEARCH_ENTRY`의 마지막 단언이 "케이스 0건"(ERD 전 상태)이었음
- v34로 CHECK에 HEADLESS_HOLD가 들어가서 이제는 **케이스 1건 · 트리거 `RULE` · 마커 `HEADLESS_HOLD` 하나**
- 바로 아래 INHUMAN_STEP 테스트처럼 제약을 읽어서 v34 전 DB면 0건을 기대 → 패치 안 한 DB에서도 깨지지 않음
- 결과: `./gradlew infraTest --tests '*RiskScoreBatchInfraTest'` 21개 통과

## 왜 이렇게 됐나

- 봇 점수는 40점(HEADLESS_HOLD 30 + NO_SEARCH_ENTRY 10)이라 기준점으로는 안 열림. 대신 HEADLESS_HOLD가 마커 규칙이라 `triggerOf`가 `RULE`로 연다
- NO_SEARCH_ENTRY는 마커 규칙이 아니라 점수에만 들어가고 마커에는 안 붙음
- `MarkerCodes`가 DB CHECK를 5분 캐시로 읽어서, 코드 재배포 없이 패치만으로 동작이 바뀜 → 테스트도 패치 여부를 보고 기대값을 고름

### 2. 오탐 2건 (강동균 님 [오탐 시험](../../강동균/features/오탐-시험-사람-변형.md))

### 4. 단체 예약 취소 맞추기 (concurrency.md §18.6, 단체 담당 요청)

승인된 단체는 `reservation.source = 'GROUP'`인 일반 예약 한 건이라 취소 흐름은 그대로, 분기 두 개만

**위약금**: `GroupFeeCalculator` 새로 (개인용 `CancelFeeCalculator`는 안 바꿈)

| 출발까지 | 위약금 |
|---|---|
| 2일 이상 전 | 1인 400원 (`fixed_amount`) |
| 2일 미만 ~ 출발 | 10% |
| 출발 후 20분까지 | 15% |
| 20~60분 | 40% |
| 60분 ~ 도착 | 70%, 도착 뒤는 취소 불가 |

- 분기는 `ReservationQueryService.cancelInfo` 한 곳 → 미리보기(CNL-01)·사용자 취소·관리자 유료 취소가 모두 같은 계산
- 좌석(탑승자)마다 계산, 좌석 금액을 넘지 않음. 구간이 없거나 겹치면 취소 불가 (개인과 같은 fail-closed)
- `cancellation.fee_policy_id`는 `cancel_fee_policy` FK라 단체는 NULL (구간은 `minutes_before_departure`로 다시 알 수 있음). 단체 구간 ID를 남기려면 ERD에 칸 추가 필요 → 필요하면 강동균 님께

**관리자 취소 면제 여부**: `POST /api/v1/admin/reservations/{id}/cancel` 본문에 `waiveFee`

- 안 보내거나 true = 지금처럼 면제(수수료 0, 전액 환불) → 오탐·운영 사유
- false = 사용자 취소와 같은 계산으로 수수료 (단체면 단체 위약금) → 매크로 판정. 계산 불가(출발 뒤 한도·도착 뒤)면 거절 → 면제로 다시
- outbox 페이로드에 `feeWaived`. A-07 강제 취소 화면에 "수수료·위약금 면제" 체크박스 (기본 켬)
- 개인 예약도 같은 옵션을 씀 (매크로로 판정한 개인도 수수료를 받을 수 있게)

**같이 고친 것**: 사용자 취소 화면이 비율이 없으면 "(0%)"로 보이던 것 → 고정 금액이면 비율 생략

**테스트**: 단위 7개(`GroupFeeCalculatorTest`, 구간 경계 20분·60분·2일 포함), 통합 2개(단체 사용자 취소, 관리자 면제/유료). 처음에 테스트 기대값을 "딱 20분 → 40%"로 적었다가 `[-20, 0)` 구간이라 15%가 맞아 고침

**로컬 DB**: v36(단체)·v37(도용 카드)·v38 패치를 안 넣은 채로 전체 테스트를 돌리고 있었음 → 멈추고 넣은 뒤 다시
