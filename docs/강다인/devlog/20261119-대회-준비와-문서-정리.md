### 3. RISK-05 다시 정하기

- `tools/ml/`(강동균) 읽음: **Isolation Forest 비교는 이미 끝남** (`compare.py`). 처음 보는 봇 계열 기준 IF 36% · 부스팅 79% · 합성 87% → 실제 모델은 부스팅+IF+GRU 합성, 계정마다 점수와 근거 3개
- 내 몫은 "모델 점수를 관리자에게 보조 의견으로 보여 주기". ERD와 안 맞는 점 3개(대상 단위 vs 계정 단위, IF 전용 칼럼 이름, `model_run.algorithm` CHECK)가 있어 혼자 정하지 않고 설계안을 씀: `docs/강다인/모델-보조의견-설계.md`

  - 정답 라벨(`label`·`strategy`)은 적재하지 않음 (관리자 화면에 정답이 보이면 안 됨)
  - 1차 대회 동안은 화면에서 숨기기 (수비의 판정에 영향)
