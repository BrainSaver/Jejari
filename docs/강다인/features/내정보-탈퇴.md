# 내 정보 조회·탈퇴 (AUTH-06)

작성자: 강다인 · 코드: `src/main/java/com/jejari/member/me/` (`MyAccountService`, `web/MyAccountController`) · 화면: U-09

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/v1/me` | `{memberId, email, name(가림), phone(가림), identityVerified, status, joinedAt}` |
| DELETE | `/api/v1/me` | 본문 `{"password":"…"}` → 204. 비밀번호 틀림 401, 잠김 423, 진행 중 예약 409 `WITHDRAW_ACTIVE_RESERVATION` |

## 탈퇴 순서

```
비밀번호 재확인 (로그인과 같은 실패 카운터, 5번이면 잠김)
 → [트랜잭션] 회원 행 잠금 → 결제 전·결제 중·출발 전 확정 예약 있으면 거절
 → 기다리던 취소표 대기 CANCELED → 이름·이메일·휴대폰 암호문·해시 지움 + withdrawn_at → 비밀번호 행 삭제 → 로그인 세션 전부 폐기
```

## 규칙

| 규칙 | 이유 |
|---|---|
| 비밀번호 재확인, 로그인과 같은 잠금 카운터 | 액세스 토큰만 훔쳐 계정을 지우지 못하게 / 탈퇴 API로 비밀번호 무차별 대입 우회 차단 |
| 진행 중 예약이 있으면 거절 | 표와 환불이 주인 없이 남지 않게 (먼저 취소 안내) |
| 개인정보는 지우고 이메일 자리는 `withdrawn-{id}@withdrawn.invalid` | 최소 보관, 같은 이메일로 재가입 가능 |
| CI·기기·결제 수단 해시는 남김 | 탈퇴 후 재가입으로 위험 점수·매수 제한 세탁 방지 (ERD "위험 이력은 보존 기간 후 파기") |
| 한계: 탈퇴 전에 받은 액세스 토큰은 15분 남지만, 회원 조회가 탈퇴 회원을 빼서 내 정보·대기열 등은 막힘 | |
