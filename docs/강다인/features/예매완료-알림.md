# 예매 완료 알림 (EVT-06 추가)

작성자: 강다인 · 2026-11-19 · 코드: `notification/NotificationEventHandler`·`NotificationService` (길동현 님 알림에 추가), `frontend/src/user/Notifications.jsx`·`Reservations.jsx` · ERD v30

## 한 줄 요약

결제가 끝나 예약이 확정되면 알림함에 **"예매가 완료됐어요 · 00049 열차 · 11월 19일(목) 15:45 · 서울 → 부산 · 2호차 7A"**가 뜨고, [예매 내역 보기]를 누르면 그 표가 펼쳐진 채로 열린다.

## 흐름

```
결제 승인 → RESERVATION_CONFIRMED (outbox → Kafka) → 알림 소비자 → notification (type CONFIRMED) → 발송기 → 알림함
GET /api/v1/notifications → 예약 알림이면 trip {trainNo, runDate, departureAt, fromName, toName, seats}
알림 누름 → /reservations?open={예약 번호} → 그 표 펼침 + 스크롤
```

## 규칙과 이유

| 규칙 | 이유 |
|---|---|
| 표 요약은 **내 예약일 때만** (`WHERE r.member_id = ?`) | 알림의 예약 번호가 남의 것이어도 그 표 내용은 나가지 않게 |
| 알림함 한 쪽(최대 50건)을 **한 번의 조회**로 요약 | 알림마다 조회하면 N번 |
| DB 제약에 CONFIRMED가 없으면 **그 알림만 건너뜀** (넣기 전에 확인, 5분마다 다시) | 넣다가 CHECK에 걸리면 알림 처리기가 그 이벤트를 끝없이 재시도하며 다른 알림까지 멈춤. ERD 패치(v30)를 적용하면 재시작 없이 켜짐 |
| 만료·환불 알림도 예매 내역에서 그 표를 펼침 | 같은 화면 이동 |

## 테스트
