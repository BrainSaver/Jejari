# 케이스 판정·조치, 마스킹 해제 (ADM-06)

작성자: 강다인 · 코드: `src/main/java/com/jejari/risk/admin/` (`CaseActionService`, `web/CaseActionController`) · 화면: A-06

## API

| 메서드 | 경로 | 권한 | 설명 |
|---|---|---|---|
| POST | `/api/v1/admin/cases/{id}/actions` | REVIEWER 이상 | `{"verdict":"MACRO","action":"RESTRICT","memo":"사유"}` |
| POST | `/api/v1/admin/cases/{id}/unmask` | SUPERVISOR | `{"memo":"사유"}` → 연결 계정 실명·전화·이메일 원문 |

| 판정 | 허용 조치 | 결과 |
|---|---|---|
| NORMAL (오탐) | CLEAR만 | 점수 0·CLEARED(+이력), 캐시 삭제, 케이스 DISMISSED, RESTRICTED였던 계정 → ACTIVE (BANNED는 그대로) |
| RESELLER·MACRO·CANCEL_ABUSE | CONFIRM | 점수 CONFIRMED, 케이스 CONFIRMED |
|  | RESTRICT | 위 + ACTIVE 계정 → RESTRICTED (대기열 최대 패널티, 취소표 불가) |
|  | BAN | 위 + 계정 BANNED + 로그인 세션 폐기(`revoke_reason = ADMIN`) |

## 규칙

| 규칙 | 이유 |
|---|---|
| 케이스 행을 잠그고 열린 케이스만 처리, 닫혔으면 409 `CASE_CLOSED` | 두 관리자가 동시에 판정해도 한 번만 (테스트로 확인) |
| admin_action·케이스·점수·회원 상태·세션을 한 트랜잭션 → 커밋 뒤 `risk:*` 캐시 즉시 갱신 | 대기열 패널티가 재동기화(10분)를 기다리지 않고 바로 반영 |
| CLEAR 시각 = `risk_score.calculated_at` = `admin_action.acted_at` | 1분 배치가 이 뒤 증거만 다시 세서 해제한 오탐이 되살아나지 않음 |
| 사유 5자 이상 500바이트 이하, 제어 문자 제거, 판정과 안 맞는 조치는 409 `ACTION_NOT_ALLOWED` | 감사 추적, 로그 위조 방지 |
| 마스킹 해제는 UNMASK 기록을 **먼저** INSERT한 같은 트랜잭션에서만 원문을 읽음, `no-store` | 기록 없이 원문이 나가는 경로가 없음 |
| 한계: 정지 전에 발급된 액세스 토큰은 만료(15분)까지 유효 | 새로 고침(리프레시)은 세션 폐기로 바로 막힘 |

## 테스트

통합 7개 `CaseActionInfraTest`: 이용 제한(상태·케이스·점수·감사 기록·캐시 유지) / 오탐 해제(점수 0·이력·캐시 삭제·제한만 복구·정지 유지·CLEAR 시각) / 정지(계정·세션 폐기) / 잘못된 조합·짧은 사유·모르는 판정·닫힌 케이스·없는 케이스 / 동시 판정 2건 → 1건 / VIEWER 403 / 해제 권한·사유 필수·기록·원문
