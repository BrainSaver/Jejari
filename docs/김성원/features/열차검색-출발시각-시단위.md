# 열차 검색 출발 시각 (시 단위 선택)

작성자: 김성원 · 코드 위치: `frontend/src/user/Search.jsx`

## 한 줄 요약

열차 검색의 "출발 시각 이후"를 분 단위 입력이 아니라 **0~23시 중 시만** 고르게 해서, 검색 조건을 단순하게 하고 지난 시각을 고를 수 없게 한다.

## 어떻게 동작하나

```
시각 칸 → <select> 0시~23시 → form.time = "HH:00" → [열차 찾기] → 주소의 time 파라미터
```

- 선택지는 `HOURS`(`"00:00"`~`"23:00"`). 오늘이면 `hourNow()`보다 앞선 시는 `disabled`.
- 기본값 `defaultTime(date)`: 오늘이면 지금이 속한 시(10:48 → `10:00`), 다른 날이면 `00:00`.
- 직접 고르지 않았으면(`timeSet=false`) 검색 조건에 시각을 넣지 않고, [열차 찾기]를 누른 시점의 시로 다시 맞춘다.
- 옛 주소의 `time=10:48`은 `toHour()`가 `10:00`으로 바꿔 읽는다.

## 왜 이렇게 했나

- 분까지 고르는 입력은 모바일에서 불편하고, 열차 검색에는 "몇 시 이후"면 충분하다.
- `type=time` 대신 `<select>`를 써서 지난 시를 비활성으로 막을 수 있다.

## 주의할 점

- 화면을 오래 열어 두면 처음 연 시가 지난 시가 될 수 있다. `submit`에서 한 번 더 현재 시로 올려 검색한다.
- 시각 문자열은 `"HH:MM"` 형식이 같을 때만 `>` 비교가 맞다 (`maxTime`). 형식을 섞지 말 것.
