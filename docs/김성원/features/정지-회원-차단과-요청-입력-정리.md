# 정지 회원 차단 · User-Agent 정리 (보안 점검 후속)

작성자: 김성원 · 코드 위치: `src/main/java/com/jejari/member/MemberStatusGuard.java`, `src/main/java/com/jejari/common/web/UserAgents.java`
배경·수치: `docs/김성원/troubleshooting/20261125-정지회원-재가입과-남은-토큰으로-결제.md`, `…-비ASCII-User-Agent-로그인-500.md`, `…-좌석-선점-null-원소-500.md`

> 다른 팀원이 1~2분 안에 이해할 수 있게 짧게 씁니다.

## 한 줄 요약

정지(`BANNED`)된 회원은 **같은 명의로 다시 가입할 수 없고**, 정지 직전에 받은 토큰이 남아 있어도 **결제·정보 변경·원문 보기·탈퇴를 못 한다**. 로그인 때 받는 User-Agent는 **UTF-8 300바이트**로 잘라 저장한다.

## 어떻게 동작하나

```
가입    : 토큰 확인(peek) → forbidBannedCi(ciHash) → … → 저장 트랜잭션 안에서 한 번 더 forbidBannedCi
결제    : forbidBanned(memberId) → 막히면 선점 좌석 즉시 반환(RISK_BLOCKED) → 403 AUTH_BANNED
내 정보 : 변경·원문·탈퇴 앞에서 forbidBanned → 403   (조회 GET /me 는 연다)
```

- **`MemberStatusGuard`**: `GuestGuard`처럼 JWT가 아니라 **DB의 `member.status`**로 판단한다. 관리자가 정지하면 세션은 지워지지만 액세스 토큰은 15분 남기 때문이다.
  - `forbidBanned(memberId)` — 로그인한 회원용
  - `forbidBannedCi(ciHash)` — 가입용(아직 회원 ID가 없음). 비회원 입장(`GuestService`)과 같은 기준: 그 CI로 정지된 계정이 **하나라도** 있으면(탈퇴 계정 포함) 거절
- **`UserAgents`**: 제어 문자 제거 + UTF-8 300바이트 절단(글자 중간을 끊지 않음). 회원·비회원·관리자 로그인과 `ClientInfo`가 모두 이것을 쓴다.
- 같이 바뀐 것
  - 헤더 값이 Spring Security 방화벽에 거절되면(`RequestRejectedException`) 500이 아니라 **400**
  - 좌석 선점 `seats` 배열에 `null`이 있으면 **400**
  - `GroupAdminController`에 다른 관리자 컨트롤러처럼 클래스 단위 `ADMIN_VIEWER`

## 왜 이렇게 했나

- **모든 요청마다 상태를 보지 않은 이유**: 대기열 폴링처럼 아주 잦은 요청에 DB 조회가 붙는다. 정지 회원이 실제로 이득을 보는 건 돈·계정이 바뀌는 기능뿐이고, 이 기능들은 호출이 드물어 조회 1번이 부담이 없다. 대기열·좌석 선점·취소표 대기는 원래 DB 상태를 보고 있었다.
- **조회(GET /me)와 예약 취소는 열어 둔 이유**: 화면이 "정지된 계정"을 안내하려면 상태를 읽어야 한다. 취소를 막으면 정지 회원의 좌석이 묶이고 본인 돈도 환불되지 않는다. 취소를 허용하면 좌석이 다른 사람에게 돌아간다.
- **바이트로 자르는 이유**: `auth_session.user_agent`는 `VARCHAR2(300)` = 300**바이트**다. 글자 수로 자르면 한글 100자만 넘어도 ORA-12899로 로그인이 500이 됐다. 컬럼을 바꾸는 대신(ERD 패치 필요) 코드에서 맞췄다.

## 주의할 점

- **새로 만드는 기능에서 붙여야 한다.** 결제·계정 변경처럼 되돌리기 어려운 기능이면 `guestGuard.forbidGuest`와 `statusGuard.forbidBanned`를 같이 붙인다. 붙이지 않으면 정지 회원도 15분 동안 쓸 수 있다.
- 한글을 UTF-8 바이트 그대로 보낸 User-Agent는 로그인이 **400**이 된다(Tomcat이 헤더를 ISO-8859-1로 읽어 방화벽이 거절). 일반 브라우저 UA는 ASCII라 드물다.
- 테스트: `UserAgentsTest`(바이트 절단·이모지·제어 문자) · `SecurityAuditInfraTest`(재가입·남은 토큰·UA·null 좌석 7건, 실제 Oracle·Redis).
