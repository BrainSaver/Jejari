# 길동현 님께 · 단체 예매 ERD v36 반영

> 작성 2026-11-24 · 강동균 · 받은 파일 `docs/erd/exports/donghyeon-20261124.json`(v2) · 절차 `docs/concurrency.md` §18

v2 JSON과 §18 초안을 반영했습니다. check-erd 결과 FAIL 0, WARN 0입니다. 보내 주신 그대로가 아니라 아래 네 가지를 바꿨습니다.

## 바꾼 것

1. **`group_booking`·`group_passenger` 예시 행을 비웠습니다.**
   - 예시 행이 `member` 1번, `train_run` 1번, `station 'NAT010'`을 가리키는데, DDL에는 이 표들의 예시 INSERT가 없습니다. FK가 INSERT보다 먼저 걸리므로 ORA-02291이 납니다.
   - `consent_at`이 `'… 08:59:00'`처럼 초까지 있어서, 생성기가 TIMESTAMP로 바꾸지 않고 문자열로 넣습니다. 생성기는 `HH:MM`까지만 TIMESTAMP로 바꿉니다.
   - check-erd는 두 가지 모두 잡지 못합니다. `group_fee_policy` 5행은 FK가 없어 그대로 뒀습니다.
2. **GROUP 예약의 카운터 감소 건너뛰기를 §3 재선점에도 넣었습니다.**
   - 결제 기한이 지난 단체 HOLD를 다른 사람이 재선점하면, §3-4가 이전 예약의 `purchase_counter`를 줄입니다. 이대로면 대표자 개인 카운터가 최대 200만큼 잘못 줄어듭니다.
   - §3-1 SELECT에 `source`를 추가했고, §3-4·§10.2·§18.5를 함께 고쳤습니다. 테스트 G8도 추가했습니다.
3. **할당석이 모자랄 때는 일반 좌석 선착순으로 했습니다.** 통보 주신 결정대로입니다.
   - 말씀하신 초안 18.3a·G5b 파일은 받지 못했습니다. 그래서 1차 초안 §18.5를 바탕으로 제가 18.3a를 썼습니다.
   - 내용: 일반 좌석은 `hold.lua` SET NX로 잡고 INSERT하며, 할당석 UPDATE와 합쳐 K행이 되게 합니다. 개인 한도는 쓰지 않고, 롤백 때 일반 좌석 키는 `release.lua`로 지웁니다.
   - 다르게 쓰신 부분이 있으면 그 초안으로 바꾸겠습니다.
   - 같은 뜻으로 `group_booking` 설명("모자라면 거절")도 고쳤습니다. 그래서 내보낸 JSON과 비교하면 이 설명, 예시 행 2개, 비고의 § 참조만 다르게 나옵니다(의도한 차이).
4. **§0.4-7, §2.2-1 BLOCKED 거절, §14.1 `GROUP` 키 값은 본문에 직접 넣었습니다.** §18에는 참조만 남겼습니다.
