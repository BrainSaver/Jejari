# [frontend] PC IP(http)로 접속하면 좌석 선점·결제 버튼이 '잡는 중…'에서 멈춤

| 항목 | 내용 |
|---|---|
| 작성자 | 강동균 |
| 날짜 | 2026-11-24 |
| 상태 | 해결 |
| 관련 커밋·이슈 | `cffd0eb` |

## 1. 문제

- 현상: 2차 봇 대회 리허설에서 같은 와이파이의 휴대폰·다른 PC로 `http://113.198.238.102:8080`에 들어온 사람은
  배치도까지는 보이는데, [이 좌석 잡기]를 누르면 버튼이 '좌석을 잡는 중…'으로 멈추고 아무 일도 없었다
- 재현 조건: `localhost`가 아닌 **http** 주소로 접속 → 좌석 고르기 → [이 좌석 잡기] (결제 화면 [결제하기]도 같음)
- 영향: 진행자 PC(localhost)와 봇(localhost)은 정상이라 리허설 전까지 몰랐다. 대회에서 사람 참가자 전원이 예매를 못 할 뻔했다

## 2. 원인

- 가설 1 — 서버가 막음(속도 제한·대기열 중복): 서버 로그·Redis를 보니 입장·배치도 조회까지는 정상이고,
  **선점 요청 자체가 서버에 오지 않음**. 행동 로그에도 `VIEW_SEAT` 다음 이벤트가 없음 → 브라우저 쪽 문제
- 가설 2 — 브라우저에서 요청 전에 예외: `Seats.jsx`의 `hold()`가 요청 전에 `crypto.randomUUID()`로 멱등 키를 만든다.
  이 함수는 **보안 컨텍스트(https·localhost)에서만** 있다. http + IP에서는 `undefined`라 `TypeError`가 나고,
  `setBusy(true)` 뒤·`try` 밖이라 버튼이 '잡는 중'에 남았다
- 최종 원인: 보안 컨텍스트 전용 API(`crypto.randomUUID`)를 http 접속에서 써서 요청 전에 예외가 났다

```
member 4335  VIEW_SEAT run=1000002 st=200 availableCount=477   ← 여기서 끝 (HOLD 요청 없음)
rate:seatmap:1000002:4335  (조회는 옴)   reservation: 0건
```

## 3. 해결

| 선택지 | 장점 | 단점 | 채택 |
|---|---|---|---|
| 대회 PC에 https(자체 서명 인증서) | 코드 그대로 | 휴대폰마다 인증서 경고, 준비 시간 | |
| `randomUUID`가 없으면 `getRandomValues`로 UUID v4를 만듦 | 한 파일, http에서도 동작 | 없음 (키는 서버가 64자 이하 문자열이면 받음) | ✓ |

- 선택한 이유: 서버는 멱등 키 형식을 따지지 않고(64자 이하), `getRandomValues`는 http에서도 쓸 수 있다
- 바뀐 코드 위치: `frontend/src/lib/uuid.js`, `frontend/src/user/Seats.jsx`, `frontend/src/user/Pay.jsx`
  (`api/client.js`의 기기 ID는 이미 대체 경로가 있었다)

## 4. 수치

| 지표 | 고치기 전 (c1124v) | 고친 뒤 (c1124d 대회) |
|---|---|---|
| IP로 들어온 사람의 선점 성공 | 0 / 2명 | 30 / 30회 (휴대폰 6회 포함) |

- 측정 환경: 집계 PC 로컬 Docker Compose, 같은 와이파이의 휴대폰·노트북
- 측정 방법: 진행 화면(`loadtest/contest/web`)으로 대회 실행, `reservation` 상태 확인

## 5. 정리

- 면접용 한 줄 요약: "보안 컨텍스트 전용 API(`crypto.randomUUID`)를 http로 접속한 기기에서 써서 좌석 선점 요청이 나가기 전에 멈췄고,
  `getRandomValues` 대체 경로로 바꿔 IP로 들어온 사람의 선점 성공을 0건에서 30/30으로 만들었다."
- 다음에 비슷한 상황이면: 개발 PC(localhost)에서만 시험하지 말고 **다른 기기에서 IP로** 한 번 끝까지 눌러 본다.
  `crypto.randomUUID`·`navigator.clipboard`·`getUserMedia`처럼 보안 컨텍스트 전용 API는 대체 경로를 같이 둔다
