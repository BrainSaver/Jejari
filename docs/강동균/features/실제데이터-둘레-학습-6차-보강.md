# 6차 보강 학습 (r12) — 기기 공유 해명의 구멍 막기

## 구멍과 고친 방법
6차에서 "기기를 같이 쓰는 가족"을 풀어 주는 해명 그룹(`shared_device`)을 만들었습니다. 조건은 *연결된 계정들의 선점이 30분 넘게 떨어져 있을 것*인데, 처음에는 **첫 선점끼리만** 비교했습니다.
그래서 봇 농장이 첫 선점만 시간차를 두고, 나중 운행에서 계정 전부로 한꺼번에 사면 가족으로 풀려날 수 있었습니다.

고침: 새 특징 `min_dev_hold_gap_s_log` — 기기로 연결된 계정들의 **모든 선점** 사이 최소 간격. 이 값으로 그룹을 판단합니다. 적대 봇 `b_shift_device`에는 "나중 운행에 몰려 사는(rejoin)" 변형 40%를 넣어 계속 잡히는지 봅니다.

## 기준 달성 여부
- 달성: 사람 오탐 4.8%(≤5), 봇 탐지 96.7%(≥96), h_organizer, h_quick_regret, b_human_mimic, b_shift_device 90%·rejoin 100%, 실제 봇 36/36, 흔적 지운 실제 사람 0/6·0/27(봇 12/12)
- **미달**: h_family_device 12.1%(기준 ≤12, 거의 근접), **h_family_bulk 23.5%(≤12)**, **h_open_rusher 14.0%(≤12)**

## 권고
**r12를 `data/ml/model`로 바꾸기에는 아직 이릅니다.** 구멍은 막혔고(rejoin 100%, 가족 기기 28→12%) 전체 수치도 좋지만, 대량 구매 가족과 오픈 러셔 오탐이 기준을 넘었고 h_pc_bang·h_slow도 r8보다 나빠졌습니다. 다음 라운드에서 bulk 해명 그룹과 open_rusher 가중치를 손본 뒤 다시 판단하길 권합니다.
