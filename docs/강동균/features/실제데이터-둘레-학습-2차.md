# 실제 데이터 둘레 학습 2차 — 오탐 함정 사람 가중

## 무엇을 바꿨나
1차는 실제 대회 데이터로 맞춘 합성 데이터로 학습했다. 2차는 학습용 시드에서만 **오탐이 잘 나는 사람 유형**(h_organizer, h_open_rusher, h_quick_regret, h_family_bulk, h_quick)의 비중을 키웠다 (`--trap-boost`). 모델 코드는 그대로이고 플래그만 다르다.
- r2: `--trap-boost 3` → `data/ml/model-real-r2`
- r3: `--trap-boost 5` → `data/ml/model-real-r3` (기준 미달이라 추가로 돌려 봄)
- 환경: CPU, GRU 포함, 각 약 17분. (python3가 3.11이라 torch가 없어 `python3.13`으로 실행)

## 결과 (합성 시험 시드 99)
| 항목 | 1차 | r2 (×3) | r3 (×5) |
|---|---|---|---|
| 봇 탐지 | 97.6% | 95.8% | 96.0% |
| 사람 오탐 | 5.4% | 3.0% | 3.1% |
| h_organizer 오탐 | 63.6% | 36.4% | 36.4% |
| h_open_rusher 오탐 | 33.3% | 10.3% | 17.9% |
| h_quick_regret 오탐 | 34.5% | 6.9% | 6.9% |
| h_family_bulk 오탐 | 25.3% | 12.0% | 9.3% |
| h_quick 오탐 | 14.5% | 7.3% | 6.4% |
| b_human_mimic 탐지 | 78% | 58.5% | 63.4% |
| b_slow_drip 탐지 | 86% | 81.4% | 86.4% |

1차 숫자는 작업 지시서 기준이고, 시험 시드 구성이 다를 수 있어 정확한 비교는 아니다. 전략별 전체 표는 `strategies.md`(모델 폴더).

## 실제 데이터 (프로필에 안 쓴 것)
| 항목 | 1차 | r2 | r3 |
|---|---|---|---|
| 실제 사람 c1124c | 0/6 | **1/6** | **1/6** |
| 실제 봇 (c1124c·c1119·c1124w) | 36/36 | 36/36 | 36/36 |
| c1124c 사람, 대회 흔적 지움 | 0/6 | 0/6 | 0/6 |
| c1124d 흔적 지움 사람 / 봇 | 0/27, 12/12 | 0/27, 12/12 | 0/27, 12/12 |

## 기준 대비
- 충족: 합성 사람 오탐 ≤5%, 흔적 지운 c1124d 0/27·12/12, 실제 봇 36/36, h_open_rusher(r2 10.3%), h_quick_regret
- **미충족**: h_organizer 36%(목표 10~15%), 실제 사람 c1124c 1/6 오탐(1차는 0/6), 합성 봇 탐지 95.8~96.0%(1차보다 낮고 기준선 경계), b_human_mimic 하락
- r3(×5)은 r2보다 나아진 게 거의 없다(h_open_rusher는 오히려 악화, b_distributed 85%로 하락). 가중을 더 키우는 건 효과가 없다.

## 남은 약점
- h_organizer(주최자: 한 사람이 여러 좌석을 빠르게 잡음)는 봇의 행동과 겹쳐 가중만으로는 안 풀린다. 특징을 더 넣어야 할 가능성이 크다.
- b_human_mimic(사람 흉내 봇)은 사람 오탐을 줄인 만큼 놓친다. 둘 사이 교환 관계.
- 실제 사람 c1124c 6명 중 1명 오탐이 어떤 사람인지는 아직 안 봤다.

## 공개 데이터 후보 (내려받거나 연결하지 않음, 라이선스는 모두 직접 확인 필요)
1. Web Bot Detection Dataset (Iliou 외, Bournemouth) — https://bordar.bournemouth.ac.uk/272/ — 사람 56·봇 세션, 웹 로그+마우스 움직임. 규모 작음. 간격·마우스 특징 보정용. 라이선스 미확인.
2. EClog (Chodak·Suchacka·Chawla, Computer Networks 2020) — 온라인 상점 HTTP 요청 6개월, CSV 약 9GB, IP 마스킹. 봇 라벨은 직접 만들어야 함(user-agent 등). 요청 간격 분포 보정용. 배포처·라이선스 논문에서 확인 필요.
3. 서버 접근 로그 로봇/사람 구분 연구 (Old Dominion, arXiv 2208.12914) 및 wright.edu 로그 (arXiv 1801.09715) — 접근 간격·패턴. 상호작용 단위가 아니라 거칠다. 라이선스 미확인.
- Hugging Face의 "HumanVsBotScan" 류는 생성된 가짜 행으로 보여 쓰지 않는 게 좋다.

## 권고
**아직 `data/ml/model`을 교체하지 말 것.** r2는 사람 오탐 3.0%로 1차보다 좋지만, 실제 사람 1/6 오탐과 h_organizer 36%가 남아 있고 봇 탐지도 1차보다 낮다. 교체 전에 (1) c1124c의 오탐 1명 원인 확인, (2) h_organizer용 특징 보강 또는 규칙 쪽 예외, (3) 봇 탐지 ≥96% 유지 여부를 다시 본다. 후보로 쓴다면 r2를 쓴다.
