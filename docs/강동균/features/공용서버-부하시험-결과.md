## 발표 문장 (값을 채워서)

"CPU 4개 서버 한 대에서 동시 ___명까지 p95 ___초로 버티고, 그 위로 몰려도 대기열·로그인 대기실이 받아 서버 오류 ___%, 잘못 팔린 표 0건입니다.
같은 조건에서 개선 전 예매 p95 4.9초 → 개선 후 ___초입니다."

못 하는 것도 같이: 명절 실제 규모(수만 명) · 여러 IP에서 오는 부하(k6 PC 한 대) · 앱 2대 수평 확장(같은 CPU 4개를 나눠 씀)
