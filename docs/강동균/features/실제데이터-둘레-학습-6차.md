# 실제 데이터 둘레 학습 6차 (r10·r11)

## 무엇을 왜 바꿨나
5차 진단(`실제데이터-둘레-학습-5차-진단.md`)에서 가족 사람이 많이 잡혔습니다.
- `h_family_device`: 가족이 기기 하나를 같이 써서 "기기 공유" 증거로 막힘, 또는 좌석을 1~2장만 사서 해명 그룹(bulk) 밖에 있었음.
- `h_family_bulk`: bulk 그룹에서 P(사람)이 문턱(0.924)보다 낮았음.

6차 변경 3가지:
1. **shared_device 해명 그룹** (`--exon-shared`): 기기를 2계정 이상이 쓰되 카드는 1개 이하이고 계정 간 간격이 약 30분 이상일 때만 기기 공유 증거를 면제. 카드 공유는 여전히 막음.
2. **새 적대 봇 `b_shift_device`** (`--shift-bot`): 기기 하나에 계정 3~5개, 각자 카드, 40~240분 간격. 새 면제를 노리는 봇이라 문턱을 보정하는 데 씀.
3. **한 번에 잡은 좌석 특징** (`--hold`, r10만): max_seats_per_hold, seats_per_resv.

r10 = 1+2+3, r11 = 1+2. 새 데이터(`real-r10`)에서 r8도 같이 다시 채점해 같은 조건으로 비교했습니다.

## 새 면제를 노린 봇은?
r8은 `b_shift_device`를 46%만 잡았지만 r10·r11은 94.9%로 잡습니다. 즉 면제가 봇의 구멍이 되지 않도록 보정됐습니다. 대신 `b_distributed`·`b_slow_drip`은 r8보다 1~5%p 낮아졌습니다(풀어준 만큼의 비용).

## --hold가 도움이 됐나
조금 됐습니다. 효과가 있는 곳은 `h_family_bulk`(22.4→17.9%)뿐이고, 나머지는 거의 같습니다. c1124c 원본의 사람 오탐도 r11 2/6 → r10 1/6, `b_slow_drip`도 r10이 낫습니다(88.9% vs 85.2%). `b_human_mimic`만 r11이 1.5%p 높습니다.

## 기준 충족
r10: **h_family_bulk 17.9%(기준 12%) 하나만 미달**, 나머지 전부 충족. r11: 같은 항목 22.4%로 미달, 나머지 충족. 실제 c1124c 원본 사람의 오탐은 같은 기기를 6계정이 몇 분 간격으로 쓴 대회 흔적이라 새 그룹이 일부러 면제하지 않는 경우이며 참고만 합니다.

## 권고
**r10을 후보로 추천**합니다(r11보다 모든 면에서 같거나 낫고 h_family_bulk도 개선). 다만 h_family_bulk 12% 기준을 못 맞췄으므로 `data/ml/model`의 교체는 팀 판단에 맡깁니다(자동으로 교체하지 않음). 교체한다면 가족 다좌석 구매가 많이 걸린다는 점을 알고 가는 것입니다. 다음 단계 후보: bulk 그룹 특징 보강 또는 문턱 재보정.
