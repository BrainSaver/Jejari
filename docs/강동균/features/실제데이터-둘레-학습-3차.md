# 실제 데이터 둘레 학습 3차 (r4·r5)

## 무엇을 바꿨나
2차(r2)에서 남은 약점은 단체 총무(h_organizer) 오탐 36.4%, 사람 흉내 봇(b_human_mimic) 탐지 58.5%였습니다. 총무는 운행 수·결제 수·좌석 수 같은 **양**으로 걸렸고, 대부분 Isolation Forest(IF)가 잡았습니다. 여러 운행을 쓸어 담는 봇과 총무는 **운행마다의 행동**이 다르다고 보고 옵션 두 개(e728b23, 기본값 꺼짐)를 켰습니다.

- `--runs`: 운행별 특징 3개 (open_to_hold_med_log, fast_open_run_ratio, browse_per_run)
- `--if-no-volume`: IF 학습에서 양 특징(n_events, n_view, n_hold, n_pay, n_runs, seats_paid_ratio) 제외

| 모델 | 옵션 | 폴더 |
|---|---|---|
| r4 | `--runs --if-no-volume --trap-boost 3` | `data/ml/model-real-r4` |
| r5 | `--runs --trap-boost 3` (IF 변경만 분리해 보려고 같은 생성 데이터 사용) | `data/ml/model-real-r5` |

전략별 표: 각 폴더의 `strategies.md`. 합성 시험은 시드 99(2281 사람 · 719 봇)로 r2와 같습니다.

## 기준 충족 여부
- r4: 정한 기준 **전부 충족** (총무 3.0%, 사람 3.8%, 봇 96.1%, 흉내 61.0%, 실제 봇 36/36, 흔적 지운 사람 0/6·0/27).
- r5: 총무 27.3%로 **기준 미달** (나머지는 충족).

## 해석
- 총무 오탐을 줄인 건 **IF에서 양 특징을 뺀 것**입니다. `--runs`만 켠 r5는 36.4% → 27.3%로 조금만 좋아졌고, 뺀 r4는 3.0%까지 내려갔습니다.
- 대가가 있습니다. r4는 오픈 직후 바로 사는 사람(h_open_rusher)이 10.3% → 30.8%, 마음 바꾼 뒤 바로 취소하는 사람(h_quick_regret)이 6.9% → 20.7%로 늘었고, 대회 흔적이 있는 실제 c1124d 오탐도 늘었습니다(흔적을 지우면 0/27). 양을 보던 IF가 이런 빠른 사람도 같이 걸러주던 역할을 잃은 것으로 보입니다. 합성 사람 전체 오탐도 3.8%로 r2(3.0%)보다 높습니다.
- r5는 전체 오탐이 가장 낮고(2.7%) 빠른 사람들에 가장 너그럽지만, 총무는 여전히 4명 중 1명 넘게 걸립니다.
- 사람 흉내 봇은 두 모델 모두 61.0%로 큰 개선이 없습니다. 슬로우 드립도 그대로 81.4%입니다.
- 이번 실행에서 r4와 r5 모두 같은 `real-r4` 생성 데이터를 썼습니다. 폴더 `.eval`은 마지막(r5) 점수로 덮여서, r4 전략별 점수는 저장된 r4 모델로 시드 99를 다시 채점해 만들었습니다.
