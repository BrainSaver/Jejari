# 실제 데이터 둘레 학습 5차 (r8·r9) — 해명 모델

## 왜 했나
4차(r6)는 총무·오픈 직후 구매자는 잘 살렸지만, 마음 바꿔 취소하는 사람(h_quick_regret) 24%, 가족 대량 구매(h_family_bulk) 19%가 오탐이었습니다. **모델 하나로 이런 "함정"들을 서로 맞바꾸는** 한계입니다.

## 무엇을 바꿨나: 해명 단계
본 점수를 낸 뒤, 눈에 보이는 행동 그룹 두 곳에서만 한 번 더 봅니다.
- **취소 그룹**: 취소를 1번 이상 한 계정
- **대량 그룹**: 좌석 결제 비율 ≥ 0.75인 계정

각 그룹마다 "그 그룹의 사람 vs 봇"만 학습한 작은 모델이 "평범한 ○○ 같다"고 확신하면 점수를 50으로 낮춰 풀어 줍니다. 확신 문턱은 **그 그룹 봇이 2%(r9는 1%)만 풀리도록** 교차검증으로 정합니다. 기기나 카드를 다른 계정과 같이 쓰는 계정은 확실한 증거라 **절대 풀지 않습니다.**

- r8: 그룹 봇 누수 2% (기본값)
- r9: 그룹 봇 누수 1% (더 보수적)

해명 모델 로그: 취소 그룹 문턱 0.50(사람 100% 풀림), 대량 그룹 문턱 r8 0.924 / r9 0.983 (사람 90% / 84% 풀림).

## 봇이 풀려났나?
봇 전체 탐지는 r6 96.5% → r8 97.6%로 **오히려 올랐습니다.** 전략별로 r6보다 떨어진 것은 b_distributed 97.6%→95.1%(봇 1명) 하나뿐이고, 나머지는 같거나 올랐습니다(b_human_mimic 63.4→78.0, b_slow_drip 84.7→89.8). 다만 r6과 r8은 다시 학습한 모델이라 "해명 단계만의 효과"를 완전히 분리한 비교는 아닙니다.

## 기준 충족 여부
- r8: **미충족 2개** — h_family_bulk 20.0%(≤12%), 원본 c1124c 사람 2/6(≤1/6). 나머지는 모두 충족.
- r9: 위 2개 + h_quick 10.0%·h_pc_bang 8.5% 상승. 누수 1%로 줄여도 대량 그룹 오탐이 더 늘어 r8보다 나을 게 없습니다.
