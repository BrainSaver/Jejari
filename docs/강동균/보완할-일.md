## 팀과 정할 것

- [ ] **DEPARTED 전이**: `train_run.status`의 `DEPARTED`로 바꾸는 주체가 없다. 판매 오픈 스케줄러가 출발 시각에
  바꿀지, 승차권(TKT) 담당이 바꿀지 정한다. 정하면 `SaleOpenScheduler`에 한 줄 추가하거나 그쪽으로 넘긴다

  "선점은 됐는데 결제로 안 이어진 비율"이 보인다. 넣으면 `ReservationStatsReader`에 EXPIRED 집계 추가
- [ ] **기능설계서 미정 사항 15번**: 기획서는 관리자 "열차·노선·좌석 등록"이 필수인데 ADM-01은 P2였다.
  이번에 API를 만들었으니 "1차는 적재 스크립트" 문구를 고칠지 팀장(길동현)과 정한다
