## 어떻게 했나

```
시안 docs/ui/{화면ID}.html ─ 스타일을 .user 아래로 묶어 그대로 → frontend/src/styles/user.css
                           └ 동작은 React (api/client.js가 헤더·재시도 담당)
```

- 선점 요청은 `X-Queue-Token` + `Idempotency-Key`. 202(처리 중)면 **같은 키로** 다시 보낸다
- `SEAT_ALREADY_TAKEN`이면 배치도를 다시 읽고 대안 좌석을 보여 주고, 토큰이 만료되면 다시 줄 서기로
- 화면 주소(`/runs/**`, `/pay/**` …)를 `SpaForwardController`·`SecurityConfig.SPA_PAGES`에 등록

## 왜 이렇게 했나

- 서버 API만으로는 동시성 처리가 **보이지 않는다**. 발표·시험 때 사람이 직접 눌러 볼 화면이 있어야 해서 예매 흐름 전체를 먼저 이었다
- 다른 팀원 담당 화면은 **최소판**으로만 만들고 담당이 다듬도록 표로 넘겼다 ([전체-화면](../features/전체-화면.md)). 내가 다 다듬으면 각자 자기 기능을 설명할 수 없다
- 시안 스타일을 다시 짜지 않고 그대로 묶어 쓴 이유: 시안과 실제 화면이 달라지는 것을 막으려고

## 막힌 점과 해결

- Kafka 토픽이 없으면 대기열 입장이 30초 넘게 밀림 → [트러블슈팅](../troubleshooting/20261117-kafka-토픽이-없으면-대기열-입장이-밀림.md)

## 배운 점

- 재시도는 **같은 멱등 키**로 해야 한다. 화면에서 키를 새로 만들면 서버 멱등이 아무 소용이 없다
