# 2026-11-17 · 프론트엔드 틀 (React + Vite) + 실시간 예매 현황 화면

> 작성: 강동균 · 관련: ADM-03, 화면 A-01·A-04

## 한 일

- `frontend/` React 19 + Vite 8 프로젝트. 공통 API 클라이언트(토큰·재발급·요청 기록), 폴링 훅, 디자인 토큰 CSS(시안 그대로)
- 관리자 레이아웃(왼쪽 메뉴), A-01 로그인(최소판), **A-04 실시간 예매 현황**, 나머지 관리자 화면은 자리만
- 서버: `SpaForwardController`(화면 경로 → index.html), `SecurityConfig.SPA_PAGES`(화면·정적 파일 GET만 허용)
- Gradle: `processResources`가 `frontend/dist`를 jar의 `static/`에 넣음, `./gradlew buildFrontend`
- 단위 테스트 전체 + 통합 테스트 44개(현황·열차·관리자) 통과, Playwright로 실제 화면 확인

## 왜 이렇게 했나

- 팀 방향: 사용자 화면은 예쁘게, 관리자 화면은 백엔드가 보이게. 관리자 화면에 숫자의 출처·지연·응답 시간·traceId를 넣었다
- 배포는 앱 jar 하나로. 리프레시 쿠키 때문에 같은 출처가 가장 단순하다 (배포 문서의 GCP VM 방식 그대로)

## 생각이 바뀐 곳

- **분당 그래프 이력을 서버가 안 준다.** `RunDashboard.rates`는 "지금 기준 최근 60초" 한 묶음뿐이라, 화면이 10초마다 쌓는다.
  이력 API를 만들까 했지만 현황 화면에는 이걸로 충분하다 (보완할-일에 남김)
- **헤드리스 브라우저가 UTC라 시각이 9시간 어긋났다.** 서버 시각은 시간대 없는 `LocalDateTime`이다.
  화면에서 `+09:00`을 붙여 읽도록 고쳤다
- **시안은 좁은 화면에서 왼쪽 메뉴를 숨겼다.** 그러면 로그아웃도 못 해서 위쪽 가로 줄로 바꿨다
