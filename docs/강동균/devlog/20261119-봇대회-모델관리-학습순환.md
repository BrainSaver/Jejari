## 어떻게 했나

- 재학습 관문: 판정된 사람 오탐 ≤ 5%이고 기준보다 1%p 넘게 나빠지지 않음 · 판정된 봇 탐지 ≥ 기준 · 생성 시험 탐지 ≥ 기준 − 10%p · 실데이터 봇 쪽 비율 ≤ max(10%, 기준)
- 사람 기준 갱신은 "기준 모델이 사람 쪽으로 본 계정 + 관리자가 사람으로 판정한 계정"만 쓰고 위 2%를 뺀다

## 왜 이렇게 했나

- 판정은 규칙·모델이 연 케이스에만 붙어서, 그것만으로 다시 배우면 이미 잡던 봇만 더 잘 잡는다 (자기 확신 고리) → 의심과 상관없는 **무작위 점검 표본**의 판정이 가장 귀하다
- 모델은 보조 의견뿐: 대기열 순번·이용 제한·케이스 열기에는 쓰지 않는다

## 막힌 점과 해결

- 사람 기준 갱신이 처음엔 점수 동점 507명을 한꺼번에 잘라냄 → 순위로 자르기. 봇 20%가 섞인 시험에서 탐지 98 → 12%로 무너짐 → 기준 모델이 봇 쪽으로 본 계정을 빼서 해결
- 대회 당일 사람 참가자가 결제에서 막힘: 집계자 PC Redis에 리허설 기록이 남아 있었음

## 배운 점
