## 배운 점

- 측정용 데이터는 실제와 같은 성질이어야 한다: 시험 문서를 한꺼번에 넣으니 `_id`(저장 시각)가 모두 "지금"이라 `_id` 범위 조회가 오히려 느려 보였다 (2,206ms). 저장 시각 = ts로 다시 만들어 5ms 확인
- 인덱스를 더하기 전에 조회를 고칠 수 있는지 먼저 본다 — 이미 있는 인덱스(회원·기기·_id)로 좁히면 쓰기 비용이 늘지 않는다
