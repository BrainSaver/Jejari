## 어떻게 했나

**추적표** — 번호로 찾고, 안 나오면 통합 테스트 메서드 이름 216개를 시나리오와 하나씩 맞추고, 그래도 없으면 키워드(legal_hold·PER_DAY·priority_at…)로 찾음. "일부만"은 빠진 부분을 칸에 적음

**통합 테스트를 못 돌리는 환경에서 쓰기** — Docker가 없어 컴파일만 된다. 그래서 테스트가 기대하는 결과가 구현과 맞는지 코드를 먼저 읽었다:

```
T4·T12  이전 예약을 ID 오름차순으로 한 건씩 FOR UPDATE, 이미 EXPIRED면 건너뜀 (SeatHoldTx.expirePrevious)
T11     ORA-00001이면 UPDATE부터 한 번 더 (PurchaseCounters, 주석에 T11)
T14     요청마다 DB 카운터를 복원값으로 limit_incr.lua에 넘김 (SET NX)
T26     compensateAfterRelease = seat-release 소비자의 1단계, 값은 Oracle에서 다시 읽음
공통    Redis 정리는 compare-and-delete라 남의 키를 못 지움 / 좌석 속도 제한은 웹 층이라 서비스 호출엔 안 걸림
```

→ 셋 다 맞으면 테스트가 실패할 때는 테스트 실수보다 **진짜 버그**일 가능성이 높다.

**TrafficService 나누기** — 테스트가 대부분 `view()` 결과 전체를 보는 블랙박스라, 판정·셈을 순수 함수 클래스로 옮기고 서비스는 정적 가져오기로 불러 호출부를 그대로 뒀다. 테스트는 `stalled` 한 곳만 바꿈

## 왜 이렇게 했나

- **한글 클래스 이름은 바꾸고 한글 메서드 이름은 두었다**: 파일 이름이 되는 것은 클래스뿐이다. 메서드 수백 개를 바꾸는 대신 HTML 보고서만 그 환경에서 끔
- **"오탐 0%"라고 하지 않기로**: 0/27은 "12.5% 아래일 가능성이 높다"까지다. 그리고 2차 사람으로 정한 기준값은 2차 사람으로 평가할 수 없다 → 기준을 고정한 3차가 필요
- **대회 한도를 사람이 기억하지 않게**: 4일 방치는 사람이 restore를 잊어서였다. 이미 만들어 둔 자동 만료 장치(v39)를 대회 스크립트가 쓰게 바꿈
- **Redis SPOF는 "덜 멈추게"의 문제로 설명**: 정합성을 Redis에 걸지 않았다(좌석 DB PK, 한도 DB 카운터, 정리 outbox). 그래서 복제·Sentinel은 다음 단계지 빠진 안전장치가 아니다. 대기열 순서만 Redis에만 있는 것은 오픈 순간 진입을 DB에 쓰지 않으려고 고른 트레이드오프

## 막힌 점과 해결

- **T43 — 대기자가 없어도 60초 동안 좌석이 안 팔림** ([트러블슈팅](../troubleshooting/20261125-대기자가-없는-좌석이-60초-동안-안-팔림.md))
  - 추적표를 만들다 T43("대기자가 없으면 REOFFER를 release.lua로 풀어 일반 판매")에 테스트도, **그 일을 하는 코드도** 없다는 것을 발견
  - 설계(§9.1)에는 있는 단계를 `SeatReleaseConsumer`가 빠뜨렸고, TTL(60초)이 안전망이라 "가끔 조금 느림"으로만 보여 숨어 있었다
  - 제안 트랜잭션 **커밋 뒤** compare-and-delete로 푸는 것으로 고침. 커밋 뒤라 대기자에게 넘어간 좌석(R')은 건드릴 수 없고 같은 이벤트가 다시 와도 같다. §9.1 순서도 코드와 맞춤
- **테스트 컴파일이 MD5 해시 오류로 멈춤**: 처음엔 이 작업 환경 문제로 보고 `LC_ALL=C.UTF-8`로 넘겼는데, 평가가 같은 것을 짚어 다시 보니 저장소 문제(한글 클래스 이름)였다 — 위 첫 항목
- `status` 도우미 이름이 MockMvc의 `status()`와 겹쳐 컴파일 오류 → `statusOf`
- 깃허브 저장소 이름이 `BrainSaver/Jejari`로 바뀌어 이 세션에서 CI 상태를 API로 못 읽음 → Actions 화면에서 직접 확인 필요

## 배운 점

- 추적표는 "테스트가 있나"만 보는 게 아니라 **"코드가 그 단계를 하나"**까지 드러낸다 (T43)
- TTL 같은 안전망은 빠진 단계를 오래 숨긴다
- 평가가 짚은 것을 "내 환경 문제"로 먼저 넘겼던 게 틀렸다 — 남의 환경에서 나는 문제가 진짜 문제다
- 숫자 옆에 구간을 붙이면 말할 수 있는 것과 없는 것이 저절로 갈린다
