## 왜 했나

P1인데 담당이 나인 것이 남아 있었다. 그리고 지금까지 만든 것(좌석 선점·해제·결제 연결·판매 오픈)이
**실제로 돌고 있는지 눈으로 볼 방법이 없었다.** 통합 테스트는 통과하는데 시연에서 보여 줄 화면이 없다.

## 어떻게 했나

| 묶음 | 원천 | 비용 |
|---|---|---|
| 좌석 | Redis `seatmap:{runId}` 캐시 (`SeatMapService` 재사용) | 왕복 1회 |
| 분당 건수 | Oracle `reservation`·`payment`·`cancellation` | 쿼리 3회, 전부 인덱스 범위 |
| 대기열 | Redis `queue:*` (읽기만) | 파이프라인 1회 |
| 결과 모름 | Oracle `payment` (§6.2와 같은 식) | 쿼리 1회, 함수 인덱스 |

## 생각이 바뀐 곳

### `seat_inventory`를 COUNT하려다 틀린 숫자임을 알았다

처음엔 당연히 `SELECT status, COUNT(*) FROM seat_inventory WHERE run_id = ? GROUP BY status`를
쓰려 했다. 그런데 **좌석 선점은 진 요청이 DB에 아예 쓰지 않는다**(§17.1 C안을 내가 골랐다).
실시간 선점 상태는 DB가 아니라 Redis `seat:hold` 키에 있다. DB만 세면 선점 수가 실제보다 적게 나온다.

내가 고른 설계가 **내가 만들 화면의 데이터 소스까지 바꿔 놓은 것**이다. 락 방식을 고를 때는
TPS와 DB 왕복만 봤는데, 그 선택이 "현황을 어디서 읽나"까지 결정했다.

`SeatMapService`가 이미 Redis 키와 DB SOLD 행을 합쳐 보고 있어 그대로 불렀다. 덤으로
`seatmap` 캐시(1초)가 걸려 있어 10초 폴링이 Oracle을 두드리지 않는다.

### 새 인덱스를 만들려다 안 만들었다

"분당 예약 수"를 세려면 `reservation(run_id, created_at)` 복합 인덱스가 필요할 것 같았다.
그런데 CLAUDE.md가 쓰기 폭주 테이블에 인덱스를 더할 땐 쓰는 쿼리를 같이 적으라고 해서
먼저 기존 것으로 되는지 따져 봤다.

한 운행의 예약 행 수는 **좌석 수에 묶인다.** 1,050석이면 예약은 많아도 수천 건(취소·만료 포함)이다.
`ix_reservation_run_id`로 그 범위만 읽고 안에서 시각을 거르면 충분하다. 쓰기가 가장 몰리는
테이블에 인덱스를 하나 덜 얹었다.

### 세는 기준을 좁혀야 했다

- 결제는 `APPROVED`만. `REQUESTED`는 아직 팔린 게 아니다
- 취소는 `cancellation` 행 기준 → **만료가 빠진다**. 만료는 돈이 오가지 않아 `cancellation`
  행을 만들지 않는다(ERD `cancel_type` 설명). 강다인 씨가 취소율을 볼 때 걸릴 수 있어 문서에 적었다
- `payments.unknown`은 **전체** 기준. §6.2의 "결과 모름"은 PG 대사 문제라 운행과 상관없고,
  같은 화면 A-04가 ADM-09도 맡는다

## 막힌 점과 해결

- **통합 테스트 60개가 실패**했다. 내가 만든 것과 무관한 `BadSqlGrammarException`
  (`reservation_seq`, `member_seq`가 없다). Oracle 볼륨이 ERD v12 시절 것이어서 v13·v15·v16에서
  추가된 시퀀스 5개가 없었다. 테이블 44개는 있어서 겉으로는 정상처럼 보였다.
  - 볼륨을 다시 만들어 해결 (`docker volume rm jejari_oracle-data`). 시퀀스 6개·시드 검증
    23항목 전부 OK. 실패 60 → 18
  - **겉보기 정상을 믿으면 안 된다**는 걸 배웠다. 테이블 수만 보고 "스키마 최신"이라고 넘겼다
- 남은 18개(`MemberAuthInfraTest` 15 · `MemberQueueE2EInfraTest` 3)는 이 PC `.env`에
  `JEJARI_ENC_KEYS`·`JEJARI_PEPPER_KEYS`가 없어서다. `.env.example`이 **팀 공용 비밀값**이라고
  적어 둔 값이라 내가 만들면 안 된다. 받아서 넣어야 한다
