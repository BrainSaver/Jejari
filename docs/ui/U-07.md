# U-07 결제 결과

- 기능: PAY-02, PAY-03
- 담당: 길동현
- 시안: `docs/ui/U-07.html`

## 목적

결제 결과를 보여줍니다. 승인이면 예약 확정과 승차권 번호, 실패면 좌석이 풀렸다는 안내, 결과를 모르면 확인 중 상태입니다.

## 화면 구성

- 결과 아이콘과 문구 (확정 / 실패 / 확인 중)
- 확정: 승차권 번호, 운행·좌석, 결제 금액
- 실패: 사유, "좌석은 다른 분께 돌아갔어요"
- 확인 중: "결제 결과를 확인하고 있어요" + 자동 새로고침
- 버튼: 예매 내역 보기(U-08), 처음으로(U-03)

## 동작

1. 화면을 열면 `GET /reservations/{id}`로 상태를 읽습니다.
2. PAYMENT_PENDING이면 3초마다 다시 읽고, CONFIRMED 또는 EXPIRED가 되면 멈춥니다.
3. 1분이 지나도 결과가 없으면 "결과가 늦어지고 있어요. 확정되면 알림으로 알려드려요"로 바꿉니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/reservations/{id}` | 화면 열 때, 확인 중 폴링 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `RESERVATION_NOT_FOUND` | "예약을 찾을 수 없어요" 후 U-08 |

## 메모

- 돈이 빠졌는데 확정할 수 없으면 서버가 자동 환불합니다 (PAY-05). 이때 실패 화면에 "결제 금액은 환불돼요"를 덧붙입니다.
