# A-04 실시간 예매 현황

- 기능: ADM-03, ADM-07, ADM-09
- 담당: 강동균 · 강다인 · 길동현
- 시안: `docs/ui/A-04.html`

## 목적

판매가 열린 운행의 상황을 10초마다 봅니다. 결과를 모르는 결제를 처리하고, 필요하면 예약을 강제 취소합니다.

## 화면 구성

- 운행 선택
- 지표 카드: 판매, 선점 중, 남은 좌석, 대기열 길이, 입장 속도, 결제 결과 모름
- 분당 예약·결제·취소 막대 그래프
- 결제 결과 모름 목록 (30분 이상): 결과 입력(승인·실패) 버튼 (P2, 1차는 건수만)
- 예약 검색과 강제 취소 (사유 필수, 수수료 0, 전액 환불) (P2)

## 동작

1. `GET /admin/dashboard/runs/{runId}`를 10초마다 부릅니다.
2. 결과 모름 목록은 `GET /admin/payments/unknown`, 결과 입력은 `POST /admin/payments/{id}/resolve` (SUPERVISOR).
3. 강제 취소는 `POST /admin/reservations/{id}/cancel` (사유 필수, 두 번 눌러 확정).
4. 서버 지표(TPS, 응답 시간)는 Grafana 링크로 엽니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/admin/dashboard/runs/{runId}` | 10초 폴링 |
| GET | `/api/v1/admin/payments/unknown` | 결과 모름 목록 |
| POST | `/api/v1/admin/payments/{id}/resolve` | 결과 입력 |
| POST | `/api/v1/admin/reservations/{id}/cancel` | 강제 취소 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | 결과 입력·강제 취소 버튼 비활성 (VIEWER) |
