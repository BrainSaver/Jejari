# A-07 운영 설정

- 기능: ADM-08
- 담당: 조영준
- 시안: `docs/ui/A-07.html`

## 목적

결제 기한, 한도, 주기 같은 운영 값을 바꿉니다. 바꾸면 버전이 올라가고 이력이 남으며 각 서버가 다시 읽습니다.

## 화면 구성

- 그룹별 설정 목록 (queue, hold, pay, waitlist, risk, auth, scanner …): 키, 값, 단위, 설명, 버전
- 수정 폼: 새 값, 변경 사유
- 변경 이력 (누가, 언제, 이전 값 → 새 값)

## 동작

1. `GET /admin/policies/{key}` (목록은 키 묶음으로).
2. 저장은 `PUT /admin/policies/{key}` (SUPERVISOR). 버전이 다르면 다시 읽으라고 안내합니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/admin/policies/{key}` | 목록·상세 |
| PUT | `/api/v1/admin/policies/{key}` | 저장 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | VIEWER는 읽기 전용 |
