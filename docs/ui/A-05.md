# A-05 위험 사용자 목록

- 기능: ADM-04 (+ RISK-05 모델 보조 의견 칸)
- 담당: 강다인
- 시안: `docs/ui/A-05.html`
- 구현: `frontend/src/admin/Risk.jsx` (2026-11-17, 강동균 대신 제작 — 담당자 검토 필요, `docs/강동균/features/전체-화면.md`)

## 목적

위험 점수가 높은 대상(CI·결제 수단·기기)을 점수 순으로 봅니다. 이름·연락처는 마스킹하고 SUPERVISOR만 사유를 남기고 해제합니다.

## 화면 구성

- 필터: 점수 구간, 검토 상태(NONE / PENDING / CONFIRMED / CLEARED, `risk_score.review_status`), 대상 유형(CI / PAYMENT / DEVICE)
- 목록: 대상(마스킹), 점수, 주요 근거 마커, **모델 의견**, 연결 계정 수, 케이스 상태, 최근 활동
- 모델 의견 (RISK-05, 2026-11-23): 대상에 묶인 계정 중 가장 높은 모델 점수 + "봇 쪽 / 사람 쪽"(문턱 기준), 일부 계정만 점수가 있으면 `2/3계정`. 마우스를 올리면 가장 높게 본 모델. 판정 참고용이라 필터·정렬에는 안 씀. 숨김 설정·사용 중인 모델 없음이면 칸을 빼고 이유 한 줄
- 행을 누르면 A-06 케이스 상세

## 동작

1. `GET /admin/risks?minScore=&status=`, 케이스 목록은 `GET /admin/cases`.
2. 마스킹 해제는 A-06에서 사유를 쓰고 `POST /admin/cases/{id}/unmask` (이력 기록).

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/admin/risks?minScore=&status=` | 목록 |
| GET | `/api/v1/admin/cases` | 케이스 상태 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | 해제 버튼 숨김 |
