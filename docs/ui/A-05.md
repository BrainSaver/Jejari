# A-05 위험 사용자 목록

- 기능: ADM-04
- 담당: 강다인
- 시안: `docs/ui/A-05.html`

## 목적

위험 점수가 높은 대상(CI·결제 수단·기기)을 점수 순으로 봅니다. 이름·연락처는 마스킹하고 SUPERVISOR만 사유를 남기고 해제합니다.

## 화면 구성

- 필터: 점수 구간, 검토 상태(NONE / PENDING / CONFIRMED / CLEARED, `risk_score.review_status`), 대상 유형(CI / PAYMENT / DEVICE)
- 목록: 대상(마스킹), 점수, 주요 근거 마커, 연결 계정 수, 케이스 상태, 최근 활동
- 행을 누르면 A-06 케이스 상세

## 동작

1. `GET /admin/risks?minScore=&status=`, 케이스 목록은 `GET /admin/cases`.
2. 마스킹 해제는 A-06에서 사유를 쓰고 `POST /admin/cases/{id}/unmask` (이력 기록).

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/admin/risks?minScore=&status=` | 목록 |
| GET | `/api/v1/admin/cases` | 케이스 상태 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | 해제 버튼 숨김 |
