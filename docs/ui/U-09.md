# U-09 내 정보·결제 수단

- 기능: AUTH-06, AUTH-07
- 담당: 강다인 · 길동현
- 시안: `docs/ui/U-09.html`

## 목적

내 정보를 보고 결제에 쓸 가상 카드를 등록합니다. 탈퇴도 여기서 합니다.

## 화면 구성

- 내 정보: 이름(마스킹), 이메일, 휴대폰(마스킹), 본인인증 여부
- 결제 수단 목록과 등록 폼 (가상 카드번호, 별칭)
- 로그아웃, 탈퇴 (두 번 눌러 확정)

## 동작

1. 화면을 열면 `GET /me`, `GET /me/payment-methods`.
2. 카드를 등록하면 `POST /me/payment-methods`. 서버는 카드번호 해시만 저장합니다.
3. 로그아웃은 `POST /auth/logout` 후 U-01, 탈퇴는 `DELETE /me` 후 U-01.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/me` | 화면 열 때 |
| GET | `/api/v1/me/payment-methods` | 화면 열 때 |
| POST | `/api/v1/me/payment-methods` | 카드 등록 |
| POST | `/api/v1/auth/logout` | 로그아웃 |
| DELETE | `/api/v1/me` | 탈퇴 |

## 메모

- 결제 수단 해시는 위험 점수의 묶음 키입니다. 실제 카드번호를 넣지 않도록 "가상 카드번호" 안내를 둡니다.
