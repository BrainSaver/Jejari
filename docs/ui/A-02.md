# A-02 노선·역·열차·좌석 관리

- 기능: ADM-01
- 담당: 강동균
- 시안: `docs/ui/A-02.html`

## 목적

역, 노선, 차량 유형, 열차를 등록합니다. 열차를 만들면 차량 유형의 좌석 수만큼 좌석이 자동으로 생깁니다.

## 화면 구성

- 탭: 역 / 노선 / 차량 유형 / 열차
- 목록 표와 검색
- 등록·수정 폼 (오른쪽)
- 열차 등록 시 호차 구성과 생성될 좌석 수 미리보기

## 동작

1. 탭별로 `GET /admin/{stations|routes|car-types|trains}`.
2. 저장은 POST(새로)·PUT(수정). 역·노선·차량 유형은 지우지 않는 참조 데이터라 삭제 버튼이 없습니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| CRUD | `/api/v1/admin/stations` | 역 |
| CRUD | `/api/v1/admin/routes` | 노선 |
| CRUD | `/api/v1/admin/car-types` | 차량 유형 |
| CRUD | `/api/v1/admin/trains` | 열차 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | SUPERVISOR가 아니면 저장 버튼 비활성 |
