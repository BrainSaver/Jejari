# A-06 케이스 상세 (타임라인·판정·재생)

- 기능: ADM-05, ADM-06, ADM-11
- 담당: 강다인
- 시안: `docs/ui/A-06.html`

## 목적

한 케이스의 이벤트를 시간순으로 보고 의심 구간과 발동 규칙을 확인한 뒤 판정·조치합니다. 같은 CI·기기·결제 수단의 다른 계정 이벤트도 함께 봅니다.

## 화면 구성

- 케이스 요약: 대상, 점수, 상태, 연결 계정
- 점수 변화 그래프
- 타임라인: 이벤트(VIEW_TRAIN, QUEUE_ENTER, SEAT_HOLD, PAY, CANCEL), 계정별 색, 의심 구간 강조, 발동 마커
- 판정: RESELLER / MACRO / CANCEL_ABUSE / NORMAL
- 조치: CONFIRM / CLEAR / RESTRICT / BAN, 사유 입력
- 마스킹 해제 (SUPERVISOR, 사유 필수)
- "재생" 버튼 (P2, 화면 녹화)

## 동작

1. `GET /admin/cases/{id}`, `GET /admin/cases/{id}/timeline`.
2. 판정·조치는 `POST /admin/cases/{id}/actions`. 조치는 바로 위험 점수 캐시와 회원 상태에 반영됩니다.
3. CLEAR(오탐 해제)는 점수를 초기화합니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/admin/cases/{id}` | 화면 열 때 |
| GET | `/api/v1/admin/cases/{id}/timeline` | 타임라인 |
| POST | `/api/v1/admin/cases/{id}/actions` | 판정·조치 |
| POST | `/api/v1/admin/cases/{id}/unmask` | 마스킹 해제 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | REVIEWER 미만이면 판정 영역 읽기 전용 |

## 메모

- 기획서의 차별점인 화면입니다. 1차는 타임라인과 하이라이트, 영상처럼 재생(ADM-11)은 P2.
