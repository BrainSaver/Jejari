# U-03 메인·운행 검색 결과

- 기능: TRN-01, TRN-02, TRN-03
- 담당: 강동균
- 시안: `docs/ui/U-03.html`

## 목적

출발역, 도착역, 날짜로 운행을 찾고 등급별 운임과 남은 좌석을 봅니다. 대기열 없이 누구나 볼 수 있습니다.

## 화면 구성

- 검색 영역: 출발역, 도착역(바꾸기 버튼), 운행일
- 운행 카드: 열차 번호, 출발→도착 시각, 소요 시간, 등급별 운임과 남은 좌석, 판매 상태
- 판매 상태별 버튼: 예매하기(ON_SALE) / 예매 오픈 전 / 마감 / 매진이면 취소표 대기
- 하단 탭: 검색, 예매 내역, 취소표, 알림, 내 정보

## 동작

1. 화면을 열면 `GET /stations`로 역 목록을 채웁니다.
2. 검색을 누르면 `GET /runs?from=&to=&date=`.
3. 예매하기를 누르면 로그인 확인 후 U-04 대기열로 갑니다 (로그인 안 했으면 U-01).
4. 매진 등급은 "취소표 대기"로 U-10 신청 화면을 엽니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/stations` | 화면 열 때 |
| GET | `/api/v1/runs?from=&to=&date=` | 검색 |
| GET | `/api/v1/runs/{runId}` | 운행 카드 펼칠 때 (운임 상세) |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `RUN_NOT_ON_SALE` | 버튼 대신 "예매 오픈 전 · 02-01 10:00" 또는 "마감" |

## 메모

- 남은 좌석 수는 캐시(`seatmap:{runId}`) 값이라 조금 늦을 수 있습니다.
