# 제자리 디자인 기준 (DESIGN.md)

화면 시안(`docs/ui/*.html`)과 실제 프론트엔드가 같이 따르는 기준입니다. 값은 시안 HTML의 `:root` CSS 변수와 같습니다. 화면 코드에서는 색·크기를 직접 쓰지 말고 변수 이름을 씁니다.

## 방향

**전통 한지 + 편안한 화면** (팀장 시안 기준). 따뜻한 한지 바탕에 먹색 글자, 큼직한 글씨와 눌리는 버튼으로 누구나 쉽게 예매하게 합니다.

- 처음부터 글자가 크고(본문 17px), 위쪽 도우미 줄(글자 크기, 음성 안내, 전화 도움)이 늘 보입니다.
- 화면마다 "무엇을 누르면 되는지" 한 줄 안내를 둡니다.
- 한국풍은 한지 바탕, 오방색 띠, 창살 무늬(남색 판), 인장(낙관) 로고와 "확정" 도장, 명조 제목으로 냅니다.
- 화면을 덮는 말풍선·팝업 안내는 쓰지 않습니다. 안내는 본문 안에 둡니다.

## 색

| 변수 | 값 | 역할 |
|---|---|---|
| `--ink` / `--night` | `#162436` | 먹색. 기본 글자, 주요 버튼, 위쪽 메뉴·남색 판 |
| `--ink2` | `#243852` | 보조 글자 |
| `--mut` | `#57534E` | 설명 글자 (한지 바탕 대비 6:1 이상) |
| `--faint` | `#6B635A` | 약한 글자 (4.5:1 이상 유지) |
| `--paper` | `#F6F1E3` | 한지 바탕 (닥나무 결 무늬를 옅게 얹음, `--hanji`) |
| `--card` | `#FFFDF8` | 밝은 한지 카드 |
| `--line` / `--line2` | `#D5CBB8` / `#EFE8D5` | 한지 결 테두리 / 구분선 |
| `--sign` | `#F2B705` | 황금. 남색 위 주요 버튼, 현재 위치, 남은 시간, 안내 상자 테두리 |
| `--go` | `#15803D` | 솔잎 초록. 판매 중, 확정, 성공 |
| `--amber` | `#F2B705` | 선점 중, 결제 대기, 오픈 전 (글자는 `--amber-d` `#8A4B00`) |
| `--stop` / `--seal` | `#B91C1C` | 인장 빨강. 매진, 실패, 삭제, 결제 결과 모름, 로고·도장, 전화 도움 |
| `--saek` | 오방색 띠 | 적 `#B91C1C` · 황 `#F2B705` · 청록 `#15803D` · 청 `#1D4ED8` · 주홍 `#D97757` |

- 빨강은 매진·실패·위험과 인장에만 씁니다. 금액이나 선택한 좌석을 빨갛게 칠하지 않습니다.
- 상태는 색만으로 구분하지 않고 글자를 같이 씁니다 (`판매 중`, `매진 (표 없음)`).
- 다크 모드는 없습니다.

## 글꼴

| 역할 | 글꼴 | 굵기 |
|---|---|---|
| 본문·버튼·숫자 | Noto Sans KR | 400, 500, 700, 900 |
| 화면 제목·첫 화면 문구·도장 | Noto Serif KR | 700, 900 |

크기 (사용자 화면): 13.5 · 15 · 17(본문) · 23(화면 제목, 모바일) · 34(화면 제목, PC) · 36~44(시각) · 50(첫 화면). 관리자 화면 본문은 14px. 글자 크기 버튼은 화면 전체를 보통 1배 / 크게 1.15배 / 아주 크게 1.3배로 키웁니다.

## 간격·폭

- 4px 단위: 4, 8, 12, 16, 24, 32, 48.
- 본문 폭 1120px, 좁은 화면(예매 내역·알림·결제 결과) 760~800px. 좌우 여백 PC 32px, 모바일 16px.
- 960px 이상이면 PC 배치(위쪽 메뉴, 2단), 600~959px는 본문 680px, 그보다 좁으면 모바일 배치(아래 탭).

## 모양

- 모서리: 카드 16px, 버튼·입력 12px, 배지 8px, 시트 위쪽 20px.
- 카드: 2px 한지 테두리 + 옅은 그림자.
- 버튼: 아래로 3px 그림자를 준 입체 버튼, 누르면 2px 내려감. 높이 58px(사용자) / 38px(관리자).
- 남색 판(검색판, 결제 기한, 대기열, 로그인 왼쪽, 관리자 메뉴)에는 창살 무늬(`--salt`)와 위쪽 오방색 띠.

## 컴포넌트

- **위쪽 도우미 줄**(`.sbar`, 모든 사용자 화면 맨 위): "편안한 화면", 글자 크기 보통/크게/아주 크게, 음성 안내 듣기(켰을 때만 그 화면 안내를 읽음), 전화 도움 1588-0000. 고른 값은 다른 화면에서도 유지 (실제 앱은 회원 설정에 저장).
- **안내 한 줄**(`.guide`): 황금 테두리 상자. 화면에서 할 일을 버튼 이름 그대로 적음.
- **예매 단계**(`.flow`): 줄 서기 → 좌석 고르기 → 결제 → 확정. 대기열·좌석·결제·확정 화면 위.
- **뒤로 가기**: 글자를 함께 ("열차 다시 고르기", "좌석 다시 고르기", "로그인으로").
- **운행 카드**: 왼쪽 8px 상태색 띠 + 먹색 열차 번호 + 노선 선. PC에서는 가로로 나뉨(왼쪽 운행, 오른쪽 운임·버튼).
- **시간 만료·실패**: 무슨 일이 있었는지 + 다음 행동 버튼("다시 줄 서기", "다시 열차 찾기", "나란히 빈 좌석 골라 주기").
- **확정 화면**: "확정" 도장, "휴대폰 문자로 승차권 받기", "큰 글씨로 인쇄하기".
- **삭제·취소**: `alert`/`confirm` 대신 두 단계 버튼("한 번 더 누르면 …").

## 말투

- 존댓말, 짧은 문장, 버튼 이름은 누르면 일어나는 일 ("이 좌석 잡기", "119,600원 결제하기").
- 쉬운 말: "매진 (표 없음)", "A·D는 창가, B·C는 통로 쪽 좌석".
- "어르신"이라는 호칭은 쓰지 않습니다. 가족이 대신 예매하는 경우도 많아 누구에게나 맞는 말투로 씁니다.

## 그림·아이콘

- 아이콘: 2px 선 아이콘(시안 안의 SVG 세트). 이모지 쓰지 않음.
- 대기열·로그인 남색 판에만 달·학·구름·기와 선 그림 (크림색 선). 글자 뒤에 올 때는 투명도를 낮춰 대비를 지킵니다.
- 레퍼런스 이미지 자체는 쓰지 않고 새로 그렸습니다 (저작권).
