# 제자리 디자인 기준 (DESIGN.md)

화면 시안(`docs/ui/*.html`)과 실제 프론트엔드가 같이 따르는 기준입니다. 값은 시안 HTML의 `:root` CSS 변수와 같습니다. 화면 코드에서는 색·크기를 직접 쓰지 말고 변수 이름을 씁니다.

## 방향

**역 안내 표지판 + 한가위 밤.** 예매 정보는 역 표지판처럼 굵고 빠르게 읽히게 하고, 한국풍은 몇 곳에만 둡니다.

- 정보 영역(운행 목록, 좌석, 결제, 관리자 표)은 흰 바탕에 굵은 고딕과 신호색만 씁니다.
- 한국풍은 네 군데에만 둡니다: 색동(단청) 띠, 낙관 로고와 "확정" 도장, 남색 판의 옅은 문살 무늬, 한가위 밤 선 그림(첫 화면, 대기열, 로그인).
- 근거: 팀이 모은 레퍼런스(한가위 포스터, 단청 색, 옥색 비단, 학·구름·달). 실제 서비스 사이트와 비교하지는 않았습니다.

## 색

| 변수 | 값 | 역할 |
|---|---|---|
| `--ink` | `#13294B` | 기본 글자, 주요 버튼, 위쪽 메뉴·남색 판 (한가위 밤하늘) |
| `--ink2` | `#34466A` | 보조 글자 |
| `--mut` | `#5C6B7E` | 설명 글자, 라벨 (흰 바탕 대비 5.4:1) |
| `--faint` | `#8E9AA8` | 아주 약한 글자. 본문에 쓰지 않음 |
| `--paper` | `#EEF3F1` | 페이지 바탕 (옥빛 흰색) |
| `--card` | `#FFFFFF` | 카드·입력 바탕 |
| `--line` / `--line2` | `#D2DDD9` / `#E5EDEA` | 테두리 / 구분선 |
| `--sign` | `#E3BC6A` | 달빛 금. 남색 위 주요 버튼, 현재 위치 밑줄, 포커스 테두리 |
| `--go` | `#11584B` | 상록. 판매 중, 확정, 성공 |
| `--amber` | `#DE8F65` | 구리빛. 선점 중, 결제 대기, 오픈 전, 경고 (글자는 `--amber-d` `#8A4520`) |
| `--stop` | `#B41A23` | 단청 적색. 매진, 실패, 삭제, 결제 결과 모름 |
| `--seal` | `#B41A23` | 낙관 로고와 도장 |
| `--saek` | 단청 5색 띠 | 적 `#B41A23` · 구리 `#DE8F65` · 금 `#E3BC6A` · 상록 `#11584B` · 청 `#4F86B8` |

- 상태는 색만으로 구분하지 않고 항상 글자(`판매 중`, `매진`)를 같이 씁니다.
- 상태 배지는 꽉 찬 색: 상록·적색 위 흰 글자, 구리빛 위 짙은 글자.
- 다크 모드는 없습니다 (남색 판이 이미 어두운 면 역할).

## 글꼴

| 역할 | 글꼴 | 굵기 |
|---|---|---|
| 본문·버튼·라벨 | Gothic A1 | 500, 700, 800, 900 |
| 시각·금액·순번·열차 번호 | Overpass (표지판 숫자), `tabular-nums` | 700, 800 |
| 화면 제목·첫 화면 문구 | 나눔명조 | 800 |

크기 단계 (사용자 화면): 12.5 · 14 · 16(본문) · 20(화면 제목, 모바일) · 26/34(시각) · 34(화면 제목, PC) · 50(첫 화면). 관리자 화면 본문은 14px.

## 간격·폭

- 4px 단위: 4, 8, 12, 16, 24, 32, 48.
- 본문 폭 1120px, 좁은 화면(예매 내역·알림·결제 결과) 760~800px. 좌우 여백 PC 32px, 모바일 16px.
- 960px 이상이면 PC 배치(위쪽 메뉴, 2단), 그보다 좁으면 모바일 배치(아래 탭).

## 모양

- 모서리 2~4px. 둥근 건 원형 요소(역 동그라미, 수량 버튼 아님)와 객차 앞머리뿐입니다.
- 그림자는 첫 화면 검색 카드 하나만. 나머지는 1px 테두리.
- 선은 굵게: 표 머리 3px, 합계 위 3px, 노선 선 5px.

## 컴포넌트

- **버튼**: 주요(남색), 남색 판 위 주요(달빛 금 `.btn.ink`), 보조(남색 2px 테두리), 연한 강조(`.btn.soft`), 위험(적색 테두리 → 한 번 더 누르면 적색 채움), 비활성(회색). 높이 52px(사용자) / 38px(관리자).
- **운행 행**: 왼쪽 6px 상태색 띠 + 남색 사각 열차 번호 + 노선도(굵은 선과 역 동그라미). PC에서는 가로로 나뉨(왼쪽 운행, 오른쪽 운임·버튼).
- **탭**: 남색 3px 밑줄 위에 선택된 탭만 남색으로 채움.
- **알림 상자**: 왼쪽 5px 띠 + 연한 바탕.
- **위쪽 메뉴(PC)**: 남색 판, 아래에 색동 띠, 현재 메뉴는 달빛 금 밑줄.
- **아래 탭(모바일)**: 남색 판, 위에 색동 띠.
- **삭제·취소**: `alert`/`confirm` 대신 두 단계 버튼("한 번 더 누르면 …").

## 어르신 모드

모든 사용자 화면에 있는 선택 기능입니다. 기본은 꺼져 있고, 켜면 다른 화면으로 가도 유지됩니다 (실제 앱은 회원 설정에 저장, 시안은 `window.name`).

- **켜는 곳**: PC는 위쪽 메뉴의 "어르신 모드" 버튼, 모바일은 오른쪽 아래 둥근 버튼.
- **켜면 생기는 것**: 메뉴 아래 노란 도구 줄(글자 크기 크게/아주 크게, 음성 안내 듣기, 전화 도움 1588-0000, 끄기)과 화면마다 "무엇을 누르면 되는지" 한 줄 안내(`.guide`).
- **글자 크기**: 화면 전체를 1.15배 / 1.3배 확대(`zoom`). 보조 글자는 더 진하게, 버튼은 58px 이상.
- **음성 안내**: 사용자가 켰을 때만 그 화면의 안내 한 줄을 읽어 줍니다 (브라우저 음성 합성). 말풍선처럼 화면을 덮지 않습니다.
- **말투**: 기본 화면은 누구에게나 맞는 중립적인 말투. "어르신"이라는 말은 모드 이름에만 씁니다 (가족이 대신 예매하는 경우도 많음).

모드와 상관없이 모든 사용자에게 적용하는 것:

- 예매 단계 표시(줄 서기 → 좌석 고르기 → 결제 → 확정, `.flow`)를 대기열·좌석·결제·확정 화면 위에.
- 뒤로 가기에 글자: "열차 다시 고르기", "좌석 다시 고르기", "로그인으로".
- 시간 만료 상태: 좌석 고르는 시간·결제 기한이 끝나면 무슨 일이 있었는지와 다음 행동("다시 줄 서기", "다시 열차 찾기").
- 좌석을 놓치면 "나란히 빈 좌석 골라 주기", 확정 화면에 "휴대폰 문자로 승차권 받기"·"큰 글씨로 인쇄하기".
- 쉬운 말: "매진 (표 없음)", "A·D는 창가, B·C는 통로 쪽 좌석".

## 그림·아이콘

- 아이콘: 2px 선, 각진 끝(시안 안의 SVG 세트). 이모지 쓰지 않음.
- 한가위 밤 선 그림: 남색 바탕에 크림색(`#F2E6C8`) 선. 달·학·구름·기와·별만. 글자 뒤에 올 때는 투명도를 낮춰 글자 대비를 지킵니다.
- 레퍼런스 이미지 자체는 쓰지 않고, 방식만 빌려 새로 그렸습니다 (저작권).
