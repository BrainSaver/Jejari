# A-01 관리자 로그인

- 기능: AUTH-05
- 담당: 조영준
- 시안: `docs/ui/A-01.html`

## 목적

관리자 계정으로 들어옵니다. 회원 로그인과 같은 방식이고 권한(VIEWER / REVIEWER / SUPERVISOR)에 따라 메뉴가 달라집니다.

## 화면 구성

- 아이디, 비밀번호
- 로그인 버튼
- 오류 문구

## 동작

1. `POST /admin/auth/login` 성공 시 A-04로 이동합니다.
2. 권한이 없는 메뉴는 숨기고, 직접 들어오면 `ADMIN_FORBIDDEN`을 보여줍니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| POST | `/api/v1/admin/auth/login` | 로그인 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `AUTH_INVALID_CREDENTIALS` | "아이디 또는 비밀번호가 맞지 않아요" |
| `AUTH_LOCKED` | "잠긴 계정이에요" |

## 메모

- TOTP 2단계 인증은 P3.
