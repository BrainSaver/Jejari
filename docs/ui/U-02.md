# U-02 회원가입·모의 본인인증

- 기능: AUTH-01, AUTH-02
- 담당: 강다인
- 시안: `docs/ui/U-02.html`

## 목적

모의 본인인증으로 CI를 만든 뒤 가입합니다. 같은 사람은 늘 같은 CI가 나와서 다계정이 묶입니다.

## 화면 구성

- 1단계 본인인증: 이름, 휴대폰 번호, 인증 수단(MOCK_PASS / MOCK_PHONE)
- 2단계 계정: 이메일, 비밀번호, 비밀번호 확인
- 단계 표시 (1/2, 2/2)
- 가입 완료 안내

## 동작

1. 인증하기를 누르면 `POST /auth/verify`, 성공하면 2단계로 넘어갑니다 (인증 결과 토큰을 들고 감).
2. 가입하기를 누르면 `POST /auth/signup`. 성공하면 U-01로 이동하고 "가입했어요" 안내.
3. 비밀번호 규칙(길이 등)은 입력 중에 바로 표시합니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| POST | `/api/v1/auth/verify` | 1단계 인증하기 |
| POST | `/api/v1/auth/signup` | 2단계 가입하기 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `AUTH_VERIFY_FAILED` | 1단계에 "본인인증에 실패했어요" |
| `AUTH_EMAIL_DUPLICATED` | 이메일 칸 아래 "이미 가입된 이메일이에요" |

## 메모

- 같은 CI로 여러 계정 가입은 막지 않습니다 (다계정 실험 대상). 매수 제한은 CI 기준으로 합산됩니다.
