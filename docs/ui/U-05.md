# U-05 좌석 선택

- 기능: RSV-01, RSV-02
- 담당: 강동균
- 시안: `docs/ui/U-05.html`

## 목적

입장 토큰을 가진 회원이 좌석을 고르고 선점합니다. 여러 좌석은 모두 잡히거나 하나도 안 잡힙니다.

## 화면 구성

- 상단: 입장 토큰 남은 시간
- 구간·등급 선택, 승객 유형(어른·어린이·경로)과 매수
- 호차 선택 탭, 좌석 배치도 (빈 좌석 / 선점 중 / 판매됨 / 내가 고른 좌석)
- 하단 고정: 고른 좌석, 금액 합계, 선점하기 버튼

## 동작

1. 화면을 열면 `GET /runs/{runId}/seats?from=&to=&grade=` (헤더 `X-Queue-Token`).
2. 좌석을 누르면 고른 목록에 넣고 빼며, 1회 한도(기본 4매)를 넘으면 더 고를 수 없습니다.
3. 선점하기를 누를 때 UUID 멱등 키를 만들어 `POST /reservations`. 재시도는 같은 키로 보냅니다.
4. 성공하면 받은 reservation_id와 결제 기한을 들고 U-06으로 갑니다.
5. 202(처리 중)이면 1초 뒤 같은 키로 다시 보냅니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/runs/{runId}/seats?from=&to=&grade=` | 화면 열 때, 호차 바꿀 때 |
| POST | `/api/v1/reservations` | 선점하기 (헤더 X-Queue-Token, Idempotency-Key) |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `SEAT_ALREADY_TAKEN` | "방금 다른 분이 잡았어요" + 배치도 새로고침, 고른 목록 비움 |
| `LIMIT_PER_RESERVATION` | "한 번에 4매까지예요" |
| `LIMIT_PER_RUN` | "이 열차는 4매까지 살 수 있어요 (본인인증 기준)" |
| `LIMIT_PER_HOLIDAY` | "이번 명절은 8매까지예요" |
| `QUEUE_TOKEN_INVALID` | "입장 시간이 지났어요" 후 U-04로 |
| `REQUEST_IN_PROGRESS` | 버튼에 "처리 중…" 유지 |
