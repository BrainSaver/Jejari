# U-04 대기열 (번호표)

- 기능: QUE-01, QUE-02, QUE-03, QUE-05
- 담당: 김성원
- 시안: `docs/ui/U-04.html`

## 목적

판매가 열린 운행에 들어가기 전 번호표를 받고 기다립니다. 위험 점수가 높으면 순번이 뒤로 갈 뿐 요청 자체를 늦추지는 않습니다.

## 화면 구성

- 운행 요약 (열차, 날짜, 구간)
- 내 순번, 앞사람 수, 예상 대기 시간, 진행 막대
- "새로고침해도 순번은 그대로예요" 안내
- 대기 그만두기 버튼

## 동작

1. 화면을 열면 `POST /runs/{runId}/queue`로 진입합니다. 이미 있으면 기존 순번이 그대로 옵니다.
2. 서버가 준 간격(1~5초)마다 `GET /runs/{runId}/queue/me`를 부릅니다. SSE·웹소켓은 쓰지 않습니다.
3. 응답에 입장 토큰이 오면 저장하고 U-05로 바로 넘어갑니다. 토큰은 300초 유효합니다.
4. 그만두기를 누르면 `DELETE /runs/{runId}/queue/me` 후 U-03으로 돌아갑니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| POST | `/api/v1/runs/{runId}/queue` | 화면 열 때 |
| GET | `/api/v1/runs/{runId}/queue/me` | 폴링 |
| DELETE | `/api/v1/runs/{runId}/queue/me` | 그만두기 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `RUN_NOT_ON_SALE` | "아직 예매가 열리지 않았어요" 후 U-03 |
| `RATE_LIMITED` | 폴링 간격을 늘리고 계속 |
