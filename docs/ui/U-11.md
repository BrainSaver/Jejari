# U-11 알림함

- 기능: EVT-06, WL-04
- 담당: 길동현
- 시안: `docs/ui/U-11.html`

## 목적

앱 안 알림함입니다. 실제 문자·푸시는 보내지 않고 여기에 쌓습니다. 알림에서 결제로 이어진 비율을 봅니다.

## 화면 구성

- 알림 목록: 종류 아이콘, 제목, 내용, 시각, 읽음 여부
- 종류: WAITLIST_OFFER(취소표 제안), PAY_REMINDER(결제 기한 2분 전), EXPIRED(예약 만료), WAITLIST_SKIPPED, REFUNDED
- 알림을 누르면 관련 화면으로 이동 (제안 → U-06, 만료 → U-08)

## 동작

1. 화면을 열면 `GET /notifications`.
2. 알림을 누르면 `PATCH /notifications/{id}/read` 후 이동합니다.
3. 하단 탭의 알림 배지는 읽지 않은 수입니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/notifications` | 화면 열 때 |
| PATCH | `/api/v1/notifications/{id}/read` | 알림 누를 때 |
