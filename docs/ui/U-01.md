# U-01 로그인

- 기능: AUTH-03
- 담당: 강다인 · 조영준
- 시안: `docs/ui/U-01.html`

## 목적

회원이 이메일과 비밀번호로 들어옵니다. 계정이 있는지 없는지 알려주지 않고, 연속 실패와 시도 과다를 막습니다.

## 화면 구성

- 로고와 서비스 이름
- 이메일, 비밀번호 입력
- 로그인 버튼, 회원가입 링크
- 오류 문구 영역 (입력 칸 위)

## 동작

1. 로그인을 누르면 버튼을 잠그고 `POST /auth/login`을 보냅니다.
2. 성공하면 액세스·리프레시 토큰을 저장하고 직전 화면(없으면 U-03)으로 갑니다.
3. 실패하면 비밀번호 칸만 비우고 오류 문구를 보여줍니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| POST | `/api/v1/auth/login` | 로그인 버튼 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `AUTH_INVALID_CREDENTIALS` | "이메일 또는 비밀번호가 맞지 않아요" (어느 쪽이 틀렸는지 말하지 않음) |
| `AUTH_LOCKED` | "5번 틀려서 15분 동안 잠겼어요" + 남은 시간 |
| `AUTH_RATE_LIMITED` | "잠시 후 다시 시도해 주세요" |
| `AUTH_BANNED` | "이용이 정지된 계정이에요" + 문의 안내 |
