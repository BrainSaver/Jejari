# U-10 취소표 대기 신청·목록

- 기능: WL-01, WL-02
- 담당: 강다인
- 시안: `docs/ui/U-10.html`

## 목적

매진된 등급에 취소표 대기를 걸고, 내 대기 목록을 보고 취소합니다. 취소표가 나오면 시스템이 대신 좌석을 잡아 알림을 보냅니다.

## 화면 구성

- 신청 카드: 운행, 구간, 등급, 매수 (1회 한도 이하)
- 규칙 안내: 같은 운행 1건, 전체 3건까지, 신청 순서대로
- 내 대기 목록: 순서, 상태(WAITING / OFFERED / ACCEPTED / EXPIRED / SKIPPED / CANCELED), 대기 취소
- OFFERED면 "결제하러 가기"(U-06)와 남은 기한

## 동작

1. 신청하기를 누르면 `POST /waitlists`. 대기열 입장 토큰은 필요 없습니다.
2. 목록은 `GET /waitlists`, 대기 취소는 `DELETE /waitlists/{id}`.
3. 제안 알림(U-11, P2)에서 들어오면 해당 대기 건을 강조합니다. 1차는 이 목록의 OFFERED 표시와 "결제하러 가기"가 제안 안내입니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| POST | `/api/v1/waitlists` | 신청하기 |
| GET | `/api/v1/waitlists` | 목록 |
| DELETE | `/api/v1/waitlists/{id}` | 대기 취소 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `WAITLIST_NOT_SOLD_OUT` | "아직 좌석이 있어요" + 예매하기 버튼 |
| `WAITLIST_DUPLICATED` | "이 운행은 이미 대기 중이에요" |
| `WAITLIST_LIMIT` | "대기는 3건까지예요" |
