# U-08 예매 내역·상세·취소

- 기능: RSV-04, CNL-01, CNL-02
- 담당: 강다인
- 시안: `docs/ui/U-08.html`

## 목적

내 예약을 상태별로 보고, 확정 예약은 수수료를 미리 본 뒤 취소합니다.

## 화면 구성

- 상태 필터: 전체 / 결제 대기 / 확정 / 취소·만료
- 예약 카드: 운행, 좌석, 금액, 상태 배지, 결제 대기면 남은 기한
- 상세: 승차권 번호(확정일 때만), 결제 상태, 취소 가능 여부
- 취소 시트: 결제 금액, 출발까지 남은 시간, 적용 구간, 수수료, 환불 예정액, 취소 확정 버튼(두 번 눌러 확정)

## 동작

1. 목록은 `GET /reservations`, 상세는 `GET /reservations/{id}`.
2. 취소하기를 누르면 `GET /reservations/{id}/cancel-quote`로 수수료를 보여줍니다.
3. 취소 확정을 누르면 `POST /reservations/{id}/cancel`. 결과는 환불 상태와 함께 다시 읽습니다.
4. 결제 전(HOLD) 예약은 "결제하기"로 U-06, "선점 취소"는 수수료 없이 바로 취소됩니다.

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/reservations` | 목록 |
| GET | `/api/v1/reservations/{id}` | 상세 |
| GET | `/api/v1/reservations/{id}/cancel-quote` | 취소 시트 열 때 |
| POST | `/api/v1/reservations/{id}/cancel` | 취소 확정 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `CANCEL_NOT_ALLOWED` | "출발 후 20분이 지나 취소할 수 없어요" |
| `PAYMENT_IN_PROGRESS` | "결제 중이라 지금은 취소할 수 없어요" |
| `RESERVATION_NOT_CONFIRMED` | 상태를 다시 읽어 표시 |

## 메모

- 1차는 예약 전체 취소만 합니다. 좌석 일부 취소는 P2.
- 수수료 예시: 3일 전 0% · 1~3일 5% · 3시간~1일 10% · 3시간 이내 20% · 출발 후 40%
