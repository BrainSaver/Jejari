# A-03 운행·명절 행사 관리

- 기능: ADM-02
- 담당: 강동균
- 시안: `docs/ui/A-03.html`

## 목적

날짜별 운행을 만들고 판매 오픈 시각을 정합니다. 명절 행사에 묶은 운행은 명절 전체 매수 제한(8매)이 적용됩니다.

## 화면 구성

- 명절 행사 목록 (이름, 기간, 판매 오픈 시각, 운행 수)
- 운행 목록 (열차, 운행일, 상태 SCHEDULED / ON_SALE / CLOSED, 오픈 시각)
- 운행 일괄 생성 폼 (열차, 기간, 요일)

## 동작

1. `GET /admin/sale-events`, `GET /admin/runs`.
2. 판매 오픈 시각이 되면 상태가 ON_SALE로 바뀝니다 (화면은 10초마다 새로고침).

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| CRUD | `/api/v1/admin/sale-events` | 명절 행사 |
| CRUD | `/api/v1/admin/runs` | 운행 |

## 오류·예외 표시

| 코드 | 화면에 보이는 것 |
|---|---|
| `ADMIN_FORBIDDEN` | 저장 버튼 비활성 |
