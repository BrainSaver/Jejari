# A-08 배포 (공용 서버)

- 기능: INF-03 (공용 서버 운영)
- 담당: 조영준
- 시안: 없음 (운영 도구, 프로젝트가 끝나면 지움)
- 구현: `frontend/src/admin/Deploy.jsx` (+ 서버 `DeployAdminController`·`DeployAdminService`) (2026-11-19), BLOCKED 승인 `DeployApprovalService` (2026-11-19, 길동현)

## 목적

팀원이 main에 올린 변경을 자동 배포 주기(20분)를 기다리지 않고 바로 공용 서버에 반영합니다. 버튼은 서버의 자동 배포 장치(`jejari-autodeploy`)를 지금 한 번 실행시킬 뿐이라, "CI를 통과한 main만", "ERD·DB 패치가 있으면 멈춤(BLOCKED)"이 그대로 적용됩니다.

## 화면 구성

- 지금 서버: 배포된 커밋(번호·제목), 마지막 판단(정상 / CI 기다림 / CI 실패 / 멈춤 / 실패)과 시각·내용, 마지막 수동 요청
- 판단별 할 일 안내
- **막힌 커밋 승인** (멈춤일 때만): 막힌 파일마다 종류(DB 패치 / 할 일 없음 / 서버에서 직접)와 할 일, 파일 내용 보기, DB 패치 [적용], 서버 작업 "처리함" 체크, 모두 끝나면 [승인하고 배포]
- "지금 배포" 두 단계 버튼, 진행 중 표시 (5초마다 다시 읽음)

## 동작

1. `GET /api/v1/admin/deploy` (VIEWER): 서버 파일 `~/jejari-app/deployed-sha`·`autodeploy.state`·`deploy-requests.log`와 `systemctl is-active`로 상태
2. `POST /api/v1/admin/deploy` (SUPERVISOR 중 서버 `.env` `JEJARI_OPS_DEPLOY_ADMIN_IDS`에 적힌 관리자): `sudo systemctl start --no-block jejari-autodeploy.service`로 시작만 걸고 바로 응답. 진행 중이면 409, 1분 안에 다시 누르면 429, 서버에서 꺼져 있으면 404
3. 배포 중에는 앱(11-19부터 1대)이 재시작돼 40초~1분 느려지고 이 화면의 요청도 잠깐 실패할 수 있음 → 화면은 오류를 숨기고 다시 읽음. 시연 중에는 누르지 않기

## 연결 API

| 메서드 | 경로 | 언제 |
|---|---|---|
| GET | `/api/v1/admin/deploy` | 상태 |
| POST | `/api/v1/admin/deploy` | 지금 배포 |
| GET | `/api/v1/admin/deploy/blocked` | 막힌 커밋과 파일별 할 일 (VIEWER) |
| GET | `/api/v1/admin/deploy/blocked/file?sha=&path=` | 막힌 파일 내용 (SUPERVISOR) |
| POST | `/api/v1/admin/deploy/blocked/patches` | DB 패치 적용 `{sha, path}` (SUPERVISOR + 허용 관리자) |
| POST | `/api/v1/admin/deploy/blocked/approve` | 승인 `{sha, confirmed:[서버 작업 경로]}` → 자동 배포 시작 (SUPERVISOR + 허용 관리자) |

## BLOCKED 승인 (11-19~)

1. `auto-deploy.sh`가 멈출 때 `~/jejari-app/autodeploy.blocked`에 커밋과 막힌 파일 목록을 남김
2. 화면이 파일을 나눔: `db/patch/vNN.sql` → [적용] (Oracle 컨테이너에서 **그 커밋의** 패치 파일 실행, 결과는 `db-patches.applied`) · `docs/erd/`·`db/seed/`·`*.md` → 할 일 없음 · 그 밖 → 서버에서 직접 할 명령 표시
3. 패치가 모두 적용되고 서버 작업을 모두 체크하면 [승인] → `autodeploy.approved`에 커밋 기록(`deploy-approvals.log`에도) → 자동 배포를 지금 한 번 실행
4. `auto-deploy.sh`는 **승인된 커밋과 고른 커밋이 같을 때만** BLOCKED를 건너뜀. 그사이 새 커밋이 골라지면 다시 멈추고 다시 승인
