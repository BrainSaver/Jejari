## 한 일: 대시보드에 행 하나 추가

김성원 님 팀 확인 요청 15번("Grafana에 대기열 지표를 노출할지")을 보니, 앱은 지표를 이미 내보내는데(`QueueMetrics`) 대시보드에 패널이 없었다.
`docker/grafana/dashboards/jejari-overview.json`의 Kafka 행과 JVM 행 사이에 **"대기열 · 좌석 속도 제한 · 결제 차단"** 행을 넣었다.

| 패널 | 쿼리 | 보는 것 |
|---|---|---|
| 대기열 인원 | `max(jejari_queue_waiting)`, `max(jejari_queue_active)` | 줄 선 사람 / 입장해 좌석 고르는 사람. 앱이 여러 대면 같은 값을 내서 `max` |
| 좌석 조회·선점 속도 제한 (분당 429) | `jejari_seat_rate_limited_total` by kind·locked, `jejari_seat_rate_limit_error_total` | 봇이 배치도를 두드리는 정도. 확인 실패는 Redis 문제로 통과시킨 수 |
| 결제 단계 위험 점수 확인 (결과별, 분당) | `jejari_payment_risk_check_total` by result | 7번 차단이 실제로 몇 번 막았는지 (blocked / passed / unknown / off) |

- 카운터는 처음 한 번 일어나야 생겨서 그전에는 "No data"가 뜬다 → `noValue`로 "0 (아직 없음)"을 보이게 했다.
- 서버 Prometheus에서 `jejari_queue_waiting`·`jejari_queue_active`가 0으로 잘 긁히는 것을 확인했다. 좌석 속도 제한 카운터는 아직 429가 없어 시계열이 없다.
