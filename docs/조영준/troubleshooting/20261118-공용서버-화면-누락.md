# [deploy] 공용 서버 첫 화면이 NOT_FOUND (화면 빌드 누락)

| 항목 | 내용 |
|---|---|
| 작성자 | 조영준 |
| 날짜 | 2026-11-18 |
| 상태 | 해결 |
| 관련 커밋·이슈 | `deploy/deploy.sh` 수정 커밋 |

> 파일 이름: `docs/조영준/troubleshooting/20261118-공용서버-화면-누락.md`

## 1. 문제

- 현상: 공용 서버 주소(`https://…sslip.io/`)를 브라우저로 열면 화면 대신 `{"code":"NOT_FOUND","message":"요청한 경로를 찾을 수 없습니다.","traceId":"…"}`
- 재현 조건: `deploy/deploy.sh`로 배포한 직후. API(`/api/v1/stations`)와 `/actuator/health`는 정상
- 영향: 팀원·시연에서 서비스 화면을 볼 수 없음 (API만 보임). 배포 확인 항목이 모두 API·포트 위주라 놓쳤고, 배포 직후 브라우저로 첫 화면을 열어 보고 발견

## 2. 원인

- 가설: 화면 파일이 jar에 없다 → 저장소 확인
- `frontend/`(강동균 님, React + Vite)는 `npm run build`로 `dist/`를 만들어야 `build.gradle`이 jar의 `static/`에 넣는다. `dist/`가 없으면 **조용히 건너뛰고** 백엔드만 빌드 (CI가 Node 없이 돌게 일부러 그렇게 둔 것)
- 최종 원인: `deploy.sh`가 `./gradlew bootJar`만 실행해 화면 없이 빌드됨. 서버에 Node 22도 없었음

```
build.gradle: "dist가 없으면(프론트를 빌드하지 않은 CI 등) 그냥 건너뛴다 → 백엔드 빌드는 Node 없이도 돈다"
deploy.sh (전): LC_ALL=C.UTF-8 TZ=Asia/Seoul ./gradlew -q bootJar
```

## 3. 해결

| 선택지 | 장점 | 단점 | 채택 |
|---|---|---|---|
| 서버에 NodeSource 스크립트로 Node 22 설치 | 명령이 짧음 | 원격 스크립트를 내려받아 바로 실행(`curl \| bash`) — 공급망 위험, 권한 정책에서도 막힘 | |
| Ubuntu 기본 `nodejs` | 패키지 그대로 | 24.04는 Node 18이라 Vite 8이 안 됨 | |
| **Node 22 컨테이너로 빌드** (`node:22-alpine`) | 서버에 Node 설치 없음, 이미 있는 Docker 사용, 버전이 이미지로 고정 | 첫 실행 때 이미지 받기 | ✓ |

- 선택한 이유: 서버에 설치하는 것을 늘리지 않고 로컬·서버 버전을 같게 둘 수 있음. `--user $(id -u)`로 돌려 `dist/`가 root 소유가 되지 않게
- 다시 안 생기게: `deploy.sh`가 화면을 빌드하고, **jar에 `static/index.html`이 없으면 배포를 멈춤** (조용히 API만 올라가는 일을 막음)
- 바뀐 코드 위치: `deploy/deploy.sh`

## 4. 수치

| 확인 | 전 | 후 |
|---|---|---|
| `GET /` | 404 `NOT_FOUND` (JSON) | 200 `text/html` (`<title>제자리</title>`) |
| `GET /admin/login` (화면 경로) | 404 | 200 (SPA 화면) |
| JS 번들 `/assets/index-*.js` | - | 200, 424KB |
| API `/api/v1/stations` | 200 | 200 (같은 출처) |

- 측정 환경: GCP e2-standard-4, 앱 2대 (한 대씩 재시작, 끊김 없음)
- 측정 방법: 내 PC에서 `curl -s -o /dev/null -w '%{http_code} %{content_type}' https://…sslip.io/`

## 5. 정리

- 면접용 한 줄 요약: "배포 스크립트가 백엔드만 빌드해 서버 첫 화면이 NOT_FOUND였고, Node 22 컨테이너로 화면을 빌드하고 jar에 화면이 없으면 배포를 멈추게 해 같은 실수가 조용히 지나가지 않게 했다."
- 다음에 비슷한 상황이면: 배포 확인에 **사용자가 실제로 여는 주소**(`/`)를 넣는다. "없으면 건너뛴다"는 빌드 설정은 배포 쪽에서 반드시 확인한다.
