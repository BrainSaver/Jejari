# 봇 대회 · 사람 참가 안내

> 고맙습니다! 여러분은 **진짜 사람**으로 참가합니다. 봇 탐지가 사람을 봇으로 잘못 잡지 않는지(오탐)를 재는 데
> 여러분의 예매 기록이 쓰입니다. **평소에 기차표를 사듯이** 하시면 됩니다. 빨리 하려고 애쓰지 않아도 됩니다.

## 1. 접속

- 진행자(강동균)와 **같은 와이파이**에 연결하고, 진행자가 알려 준 주소를 엽니다 (예: `http://192.168.0.12:8080`)
- 휴대폰·노트북 아무거나 괜찮습니다. 평소 쓰는 브라우저 그대로

## 2. 가입 — 실제 정보는 넣지 마세요

| 칸 | 넣을 것 |
|---|---|
| 이름 | 아무 가짜 이름 (예: 홍길동) |
| 휴대폰 | 아무 가짜 번호. **끝 네 자리가 0000이면 인증이 일부러 실패**하니 피하세요 |
| 이메일 | **진행자가 알려 준 형식 그대로**: `lt{태그}.human.g{번호}.{번호}@loadtest.example.com` |
| 비밀번호 | 10자 이상. 흔한 비밀번호(`password123` 등)·연속 문자(`1234567890`)·같은 글자 반복은 안 되고, 이메일 아이디가 들어가도 안 됩니다 |

- **번호**는 진행자가 한 사람에 하나씩 나눠 줍니다 (예: 3번이면 `lt{태그}.human.g3.3@loadtest.example.com`)
- 이메일 모양이 다르면 여러분 기록이 "사람"으로 집계되지 않습니다

## 3. 예매

1. 로그인 → 출발 **서울**, 도착 **부산**, 날짜는 진행자가 알려 준 날 → 검색
2. 열차를 고르고 **예매하기** → 줄 서기 → 차례가 오면 좌석 고르기
3. 1~4석, 평소 사듯이 (혼자면 1석, 가족 몫이면 여러 석)
4. 결제: 가상 카드번호 칸에 **끝자리가 1인 아무 숫자 16자리** (예: `4111 2222 3333 4441`). 실제 카드번호 금지
5. 마음이 바뀌면 예매 내역에서 취소해도 됩니다 — 그것도 평소처럼

## 하지 말 것

- 실제 이름·전화번호·카드번호
- 여러 계정 만들기, 일부러 빨리 누르기 같은 "봇 흉내" (우리는 사람 데이터가 필요합니다)

## 개인정보

- 서버는 진행자 PC 안에만 있고, 대회가 끝나면 데이터를 분석에만 씁니다
- 남는 것은 가짜 가입 정보와 화면에서 누른 기록(시각·간격·선택한 좌석)뿐입니다. IP·기기 ID는 해시로만 저장됩니다
